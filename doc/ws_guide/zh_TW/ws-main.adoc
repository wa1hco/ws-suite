== WS 使用者指南

[preface]
== 關於本指南

WS 是一套用於業餘無線電弱訊號數位通訊的程式：**WS**（主程式）、
**WS-MAP**（寬頻 Q65/FT8 監測）以及 **EME65**（用於 EME 的寬頻 JT65/Q65）。
WS 源自 __WSJT-X__，前身為 __WSJT-X Improved__。所有模式與基本操作
程序都與 WSJT-X 相同；這些內容請以
https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-3.0.0-rc1.html[WSJT-X 使用者指南]
為準。

本指南刻意寫得簡短。它說明 WS 的每個選單與每項設定，
以及 WS 相對於 WSJT-X 新增的功能。
