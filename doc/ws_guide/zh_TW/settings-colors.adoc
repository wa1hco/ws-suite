==== 突出顯示解碼

WS 依類別為解碼上色。除了 **CQ 訊息**、
**我的訊息**、**發送訊息**與 **LoTW 用戶**之外，其他都需要在**一般**分頁中勾選
**顯示 DXCC, 網格與曾經通聯狀態**。

[cols="2,5",options="header"]
|===
|設定 |功能

|突出顯示清單
|每個類別一行；勾選其核取方塊即可開啟。上下拖曳各行
以設定優先順序：位置較高的一行優先。前景與背景
分開設定，因此「未設定」的顏色會取自下方下一個已啟用的行。

|右鍵選單
|**字型顏色 ...** / **底色 ...** 選擇顏色，
**清除字型顏色** / **清除底色** 清除顏色。
**將此項重置為預設值** 會將該行恢復為 WSJT-X 預設值。

|**CQ 訊息**、**我的訊息**、**發送訊息**
|CQ、CQDX 與 QRZ 呼叫；發給您的解碼；您發送的訊息。

|**新DXCC**、**新大洲**、**新 CQ 分區**、**新 ITU 分區**、**新美國州**、**新網格**、**未曾通聯過**
|尚未在您的日誌中。**... 波段**變體：尚未在
目前波段通聯過。

|**LoTW 用戶**
|該電臺已在 <<LOTW_VALIDATION,LoTW 已驗證用戶>> 所設定的期限內
將其日誌上傳到 LoTW。

|**將突出顯示重置為 WSJT-X 預設值**
|原始的 WSJT-X 顏色與順序。新安裝時會使用這些設定。

|**將突出顯示重置為 WS 預設值**
|WS 配色，使用也適合深色樣式的粉彩色。LoTW
用戶以黑色顯示，其他電臺以深紅色顯示；來自您已通聯過的電臺的 CQ
會加上灰色背景。

|**重新掃描 ADIF 日誌**
|重新讀取 `wsjtx_log.adi` 並重建曾經通聯狀態。
按鈕會顯示 QSO 數量。您可以用日誌程式匯出的 ADIF
檔案取代此檔案。

|**按模式突出顯示**
|曾經通聯狀態依模式分別保存。

|**僅尋求網格欄位**
|只有在網格的欄位（前兩個字元，例如 JO）
尚未通聯過時，該網格才算是新的。

|**包括額外的 WAE 實體**
|以其自身名稱顯示額外的 DARC WAE / CQ Marathon 實體（例如 Sicily、Shetland Is.）。
未勾選時，則顯示為其所屬的 DXCC 國家。

|**突出顯示 73 或 RR73 訊息**
|73 與 RR73 訊息會像 CQ 一樣突出顯示，並加上國家與
曾經通聯標記。它們也會通過**只顯示CQ**過濾，此時該核取方塊
標示為 **CQ/73**。預設開啟。

|**突出顯示所有訊息**
|每則解碼訊息都會像 CQ 一樣突出顯示，並加上國家與
曾經通聯標記，而不只是 CQ 呼叫（以及使用上一個選項時的 73 訊息）。
預設關閉。

|**突出顯示橙色:** / **突出顯示藍色:**
|對下方欄位中輸入的呼號、網格、
字首與 CQ 方向，以橙色／藍色背景白字顯示。這些項目也會
觸發**警報**分頁中的**渴望的呼號, 網格, 前綴和定向呼叫**警報。
|===

**突出顯示橙色**與**突出顯示藍色**的輸入項目（大小寫皆可）：

* 呼號：每個呼號後面都加逗號，包括最後一個：`K1JT, DG2YCB,`
* 網格：`JO33, JN58,`
* 2 或 3 個字元的字首，置於分號之間：`;DL;KH6;`。單一字母的
  字首如 `;K;` 只會比對第二個字元為數字的呼號
  （K1ABC，而非 KH6ABC）。
* 所有以某一字母開頭的呼號：`;K*;`。若要排除某些字首，請將其
  置於驚嘆號之間：`;K*;!KH6!KL!KP!`
* CQ 方向，前後各加一個逗號：`,EU,` 會標示「CQ EU ...」。

[[LOTW_VALIDATION]]
==== LoTW 已驗證用戶

[cols="2,5",options="header"]
|===
|設定 |功能

|**用戶 CSV 檔案網址** / **立即取得**
|ARRL LoTW 用戶清單及其最後上傳日期的來源。
**立即取得**會下載最新副本。只有在檔案不存在且
**LoTW 用戶**突出顯示已開啟時，WS 才會自行下載。

|**上次上傳的時間早於以下時間**
|只有最後上傳時間比此期限更近的電臺，才會被視為 LoTW 用戶。
|===

==== 下載

[cols="2,5",options="header"]
|===
|設定 |功能

|**下載最新的 CTY.dat**
|從 country-files.com 更新國家、分區與字首資料，並
重新掃描日誌。**CTY 檔案版本**顯示目前使用的版本。

|**下載美國呼號所屬州資料庫**
|供**顯示美國各州**（**一般**分頁）使用的呼號對應州資料，在
訊息中沒有可用網格時使用。**呼號所屬州資料庫**顯示其大小與日期。

|**下載 CALL3.TXT 供 IARU 分區使用** / **下載 CALL3.TXT 供 EME 使用**
|供**檢索**按鈕與 JT4/JT65 深度搜尋使用的呼號與網格資料庫；
EME 版本適用於 JT65 深度搜尋。先前的檔案
會保留為 `CALL3_backup.TXT`。**CALL3 檔案版本**顯示版本。
|===
