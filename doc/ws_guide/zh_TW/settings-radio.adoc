[[SETTINGS_RADIO]]
=== 電臺

image::settings-radio.png[設定，電臺分頁,align="center"]

==== 無線電設備

[cols="2,5",options="header"]
|===
|設定 |功能

|**無線電設備**
|您的電臺型號，或掌控電臺的控制程式（DX Lab Suite
Commander、Flrig、Ham Radio Deluxe、Hamlib NET rigctl、OmniRig Rig 1/2、
TCI Client）。**無**表示不使用 CAT 控制。

|**詢問間隔**
|WS 從電臺讀取頻率與模式的頻率。1–3 秒適合大多數
電臺。對於會自行回報變更的電臺，此項為灰色不可用。
|===

==== CAT 控制

[cols="2,5",options="header"]
|===
|設定 |功能

|**序列埠**
|CAT 介面的序列埠（例如 COM3 或 /dev/ttyUSB0）。若使用
控制程式，此欄會變成**網路伺服器**或 **TCI 伺服器**
（`host:port`）；留空則使用本機的預設值。少數
SDR 套件則會變成 **USB 設備**。

|**波特率** / **數據位元** / **停止位元**
|必須與電臺的 CAT 選單相符。**預設值**會保留 Hamlib
針對您的型號所知的數值。

|**握手方式**
|通常為**無**。少數電臺，特別是部分 Kenwood 機種，需要
**硬體**（RTS/CTS）。設定錯誤會使 CAT 沒有回應。

|**強制控制線** **DTR:** / **RTS:**
|將 DTR 或 RTS 固定保持為**高**或**低**，例如用來為
介面供電。除非您確定需要，否則請留空。若該線路
在同一埠上用於 PTT，則無法使用。
|===

==== 更新 Hamlib

這些選項來自 WSJT-X Improved，WSJT-X 中並沒有。它們只能
在 Windows 上使用；在 Linux 與 macOS 上，此區塊名為 **Hamlib Version**，
只顯示目前使用的版本。

[cols="2,5",options="header"]
|===
|設定 |功能

|**64-位元** / **32-位元**
|要下載哪一個 Hamlib DLL。請選擇與您的 WS 安裝相符的版本。

|**更新 Hamlib**
|下載最新的 Hamlib DLL，通常會新增或修正對電臺的支援。
目前的 DLL 會保留為備份。重新啟動 WS 即可使用新版。

|**還原更新**
|改回已備份的 DLL，同樣需要重新啟動。

|**使用中** / **已備份**
|WS 正在執行的 Hamlib 版本與備份的版本。
|===

==== PTT 方法

[cols="2,5",options="header"]
|===
|設定 |功能

|**VOX**
|由電臺的 VOX 控制發射。不需要介面。

|**CAT**
|若電臺支援，則以 CAT 指令控制 PTT。搭配 OmniRig 或 Flrig 等
控制程式時，通常是正確的選擇。

|**DTR** / **RTS**
|以序列控制線控制電臺發射。許多 USB 電臺可以將此線路對應到
PTT（Icom：USB SEND，Yaesu：PC KEYING）。在使用**硬體**握手的
CAT 埠上無法使用 **RTS**。

|**序列埠**
|**DTR** / **RTS** 使用的序列埠；可與 CAT 埠相同。數值
**CAT** 用於 OmniRig 這類遠端切換控制線的介面。

|**啟用 TX 禁止**
|適用於與具有優先權的電臺共用波段的電臺（僅限 **DTR** / **RTS** PTT）：
當該電臺發射時，其他程式可以讓 WS 暫停發射。
|===

==== 無線電設備音訊源

[cols="2,5",options="header"]
|===
|設定 |功能

|**後方/數據口** / **前方/咪高峰**
|若電臺支援，以 CAT 選擇電臺的發射音訊輸入。
只有 PTT 方法為 **CAT** 時才有效。通常以**後方/數據口**最佳。
|===

==== 模式

[cols="2,5",options="header"]
|===
|設定 |功能

|**無** / **上邊帶** / **數據/封包**
|WS 在電臺上設定的模式。若電臺有**數據/封包**模式請使用它（通常
會選擇後方音訊輸入與較寬的濾波器），否則使用**上邊帶**。
**無**則不變更模式。
|===

==== 異頻操作

[cols="2,5",options="header"]
|===
|設定 |功能

|**無線電設備**
|使用電臺本身的異頻功能（VFO A 與 B）。

|**軟體虛擬**
|只使用 VFO A，並在每次發射時重新調諧。適用於任何電臺。

|**無**
|不使用異頻（不建議）。
|===

使用異頻時，WS 會以 500 Hz 為單位移動發射刻度頻率，讓發射音訊
保持在 1500 至 2000 Hz 之間。如此音訊諧波會落在
電臺濾波器之外，您的訊號也能保持乾淨。這適用於 FT4、FT8 與
FST4，以及在**啟用甚高頻和子模式功能**關閉時的所有模式。
都卜勒追蹤也需要異頻。

==== 測試 CAT 與測試 PTT

[cols="2,5",options="header"]
|===
|設定 |功能

|**測試 CAT**
|以這些設定連線到電臺。綠色：正常。紅色：錯誤，並顯示
訊息。

|**測試 PTT**
|在沒有音訊的情況下讓發射機發射；再按一次即可釋放。請確認
您的電臺與介面切換如預期。使用 **VOX** 時請改用主視窗上的
**調諧**。
|===

==== 無線電設備數據

這些選項來自 WSJT-X Improved，WSJT-X 中並沒有。

[cols="2,5",options="header"]
|===
|設定 |功能

|**顯示 PWR, SWR 和 ALC**
|發射時顯示輸出功率（以瓦為單位，位於**功率**
滑桿旁），並在狀態列顯示 SWR 與 ALC。SWR 超過 1.5 時欄位變成
黃色，超過 2.0 時變成紅色。需要能回報這些數值的電臺；
選擇**無**、OmniRig、DX Lab Suite Commander、Ham Radio Deluxe
或 Kenwood TS-480/850/870 時無法使用。

|**當駐波比大於 2.5 時停止發射**
|立即停止發射並顯示警告。請檢查您的天線。

|**突出顯示 ALC > 50%** / **突出顯示 ALC > 90%**
|ALC 超過限制時，狀態欄位會變成黃色／紅色，讓您
察覺過度驅動。
|===

最後三個選項需要**顯示 PWR, SWR 和 ALC**。
