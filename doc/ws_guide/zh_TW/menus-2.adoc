[[MENU_FILTERS]]
=== 過濾

image::menu-Filters.png[過濾選單]

波段活動窗格的快速過濾。它們使用的清單（忽略
清單、白名單、區域）在 menu:檔案[設定 > 過濾] 中設定，
請參閱 <<SETTINGS_FILTERS>>。所有過濾條件都可以組合使用。主視窗上的**繞過**（BP）核取方塊
只要按一下就能略過它們。當有「隱藏」過濾條件
開啟時，狀態標籤會變成青色並顯示「Receiving, Filters On」
（勾選**繞過**時為綠色的「Receiving, Filters bypassed」）。

[cols="2,5",options="header"]
|===
|選單項目 |功能

|**隱藏在波段上曾通聯的呼號**
|隱藏目前波段上已在您日誌中的呼號的訊息。

|**隱藏今天或昨天曾經通聯的呼號**
|隱藏您今天（或昨天）記錄過的呼號。除非**過濾**分頁中的對應選項
加入了昨天，否則此項目顯示為「隱藏今日已通聯的電臺」。

|**從忽略清單中隱藏呼號**
|隱藏忽略清單中的呼號。**忽略**按鈕會將 DX 呼號
加入該清單；可從**檔案**選單清除。

|**忽略在這波段上曾經通聯的電臺**
|這些電臺仍會顯示，但 WS 不會自動回應它們
（CQ: First / Max Dist / Max dB / Min dB、等待與突襲、等待與回覆）。

|**忽略今天或昨天曾經通聯的呼號**
|同上，適用於今天（或昨天）記錄過的呼號。

|**從忽略清單中忽略呼號**
|同上，適用於忽略清單中的呼號。

|**隱藏區域 1 的電臺** ... **4**
|隱藏國家名稱包含該區域所輸入文字的電臺。
輸入區域後，此項目會顯示其名稱
（例如「隱藏 Italy 的電臺」）。

|**隱藏 歐洲 的電臺**、**隱藏 北美洲 的電臺**、**隱藏 南美洲 的電臺**、**隱藏 亞洲 的電臺**、
**隱藏 非洲 的電臺**、**隱藏 大洋洲 的電臺**、**隱藏 南極洲 的電臺**
|隱藏該洲的所有電臺。方便只顯示 DX。

|**突出顯示在波段曾經通聯的呼號**
|已在此波段通聯過的呼號以灰色背景顯示。

|**突出顯示今天或昨天曾經通聯的呼號**
|今天（或昨天）記錄過的呼號以深灰底黃字顯示。

|**從忽略清單中突出顯示呼號**
|忽略清單中的呼號以深紅底黃字顯示。

|**突出顯示區域 1 的電臺** ... **4**
|來自該區域的呼號以紫色背景顯示。

|**突出顯示白名單項目**
|含有白名單項目的呼號以洋紅色背景顯示。
白名單過濾本身不必開啟。
|===

[[MENU_DECODE]]
=== 解碼

image::menu-Decode.png[解碼選單]

WS 只顯示適用於目前模式的項目。有些需要
**啟用甚高頻和子模式功能**（menu:檔案[設定 > 一般]）。

[cols="2,5",options="header"]
|===
|選單項目 |功能

|**快速**
|解碼最快，靈敏度最低。

|**正常**
|中等深度。

|**深度**
|靈敏度最佳，速度較慢，錯誤解碼的機率略高。
在 Echo、頻率校準以及啟用 VHF 功能的 JT65 中為灰色不可用。

|**使用多線程 FT8 解碼器**
|僅限 FT8。平行執行多個解碼執行緒。在熱鬧的波段上
通常能得到更多解碼。進行極弱訊號通訊時，
單執行緒的**深度**解碼器往往較佳。請在**參數**中設定。

a|**參數**

image::menu-Decode-Parameters.png[解碼，參數子選單]
a|多執行緒 FT8 解碼器的微調。除非開啟
**使用多線程 FT8 解碼器**，否則不會有任何作用。

[cols="2,5"]
!===
!**線數量** +
image:menu-Decode-Parameters-FT8_threads.png[線數量]
!**自動**（預設）會保留部分核心：邏輯核心為 2-4 個時
少用一個，5-8 個時少用兩個，9-15 個時少用三個，16 個
以上則使用 12 個。**1**-**12** 直接設定數量，上限為核心數。

!**解碼周期** +
image:menu-Decode-Parameters-Decoding_cycles.png[解碼周期]
!**1**、**2** 或 **3**（預設）個週期，每個週期 3 次掃描，因此共 3、6 或 9 次。
週期越多能找到越多弱訊號，但耗時較長。提早解碼（請參閱
**開始解碼**）一律使用 2 個週期。

!**通聯接收頻率靈敏度** +
image:menu-Decode-Parameters-QSO_RX_freq_sensitivity.png[通聯接收頻率靈敏度]
!**低**、**中度**（預設）、**高**。這是一個特殊解碼器的門檻值，
該解碼器會在 QSO 期間於您的接收頻率尋找來自 DX 呼號的
預期訊息。越高解碼越多，但錯誤解碼也越多。
在獵犬模式下一律使用**低**。

!**解碼靈敏度** +
image:menu-Decode-Parameters-Decoder_sensitivity.png[解碼靈敏度]
!**最少**：一般同步門檻值。**使用低閾值**：較低的同步
門檻值，因此會嘗試更多候選訊號。**使用子通道**（預設）：低
門檻值再加上額外的弱訊號子掃描。越靈敏也代表 CPU 負載越高。

!**開始解碼** +
image:menu-Decode-Parameters-Decoder_start.png[開始解碼]
!在 15 秒週期中何時開始解碼。
**階段-2**：約 11.8 秒提早解碼，14.1 秒最終解碼。
**階段-3**：約於 11.8、13.2 與 14.4 秒。
**早期**：於 13.8 秒解碼一次。**正常**（預設）：14.1 秒。
**最新**：14.4 秒。分階段的設定能更早顯示強訊號。

!**寬頻 DX 呼號搜尋**
!開啟（預設）：在整個通帶內以 AP 搜尋 DX 呼號的訊息。
關閉：只在接收頻率周圍的窄視窗內搜尋。

!**隱藏 FT8 重複訊息**
!開啟（預設）：若各執行緒在同一週期內將相同訊息解碼兩次，
只顯示一次，並採用較強的報告。

!**略過 a8 解碼**
!關閉「a8」嘗試：在接收頻率上解碼來自 DX 呼號的
預期訊息，此訊息由 **DX 呼號**與 **DX 網格**組成。
!===

|**平均值**
|啟用 VHF 功能的 JT4、JT65 與 Q65。將連續週期平均，以
解碼單一週期內過弱的訊號。窗格會變成**單週期解碼**
與**平均解碼**。

|**開啟深度搜尋**
|啟用 VHF 功能的 JT4 與 JT65。一般解碼失敗時，會將
訊號與由您的呼號、DX 呼號、DX 網格與 `CALL3.TXT` 組成的
可能訊息進行比對。

|**啟用增強解碼**
|兩個項目中的第一個。僅限 FT8：先驗（AP）解碼，
利用您的呼號、DX 呼號與 QSO 狀態找出更弱的訊息。
AP 解碼會標示為 `a1` ... `a8`。

|**啟用增強解碼**
|第二個項目。僅限啟用 VHF 功能的 JT65：JT65 的 AP 解碼。


|**解碼後自動清除平均值**
|在接收頻率的**容差**範圍內成功解碼後，清除
平均值，讓下一則訊息重新開始。

|**接受 WS-MAP/EME65 點擊事件**
|啟用 VHF 功能的 Q65 與 JT65（預設開啟）。在
WS-MAP 或 EME65 中點擊電臺，會在 WS 中設定 DX 呼號、網格、頻率與週期。
開啟**雙擊呼號條啟用發送**時，按兩下也會開始 QSO。它也會
帶入 EME65 轉送的解碼。

|**獨佔 WS-MAP**
|接受點擊事件時顯示。若有多個 WS 執行個體監看
同一個 WS-MAP/EME65 來源，只有持有獨佔權的執行個體會回應
點擊。若持有的執行個體 10 秒內未更新，獨佔權會
自動釋放。主視窗上的**獨佔 WS-MAP**按鈕功能相同。

a|**WS-MAP/EME65 來源**

image::menu-Decode-QMAP_source.png[WS-MAP/EME65 來源子選單]
a|WS 要監聽哪一個 WS-MAP 或 EME65 執行個體。

* **自動**（預設）與 **1**：預設執行個體（WS-MAP 設定中 Instance ID 為 1 或
未設定）。只有一個 WS-MAP 時使用此項。
* **2**、**3**、**4**：只監聽具有該 Instance ID 的執行個體。

變更來源會釋放任何獨佔權。變更立即生效；
建議之後重新啟動 WS。

|**禁用在瀑布上點擊**
|啟用 VHF 功能的 JT65 與 Q65。保護您的接收/發射偏移不因
誤點瀑布圖而改變。按住 kbd:[Alt] 仍可點擊。

|**隱藏 AP 資訊**
|僅限 FT8。從顯示的解碼中移除 `a1` ... `a9` 與 `?` 標記。

|**减少錯誤解碼**
|FT8，特殊操作模式除外。捨棄看起來不合理的
弱解碼，例如低 SNR 下 `/P`、`/R`、`R`、雜湊
呼號或競賽交換資料的奇怪組合。這些行不會寫入 `ALL.TXT`。
使用單執行緒解碼器時，若呼號不在 `ALLCALL7.TXT` 中且看起來不像
有效呼號，低於 -20 dB 的解碼也會被隱藏。

|**全雙工模式**
|在發射時持續接收與解碼，例如使用來自
第二部接收機或 WebSDR 的音訊。適用於 FT8、FT4、Q65、MSK144 及其他模式。
|===

[[MENU_MODE]]
=== 模式

image::menu-Mode.png[模式選單]

選擇操作模式。發射期間此選單會鎖定。
各模式的詳細說明請參閱 WSJT-X 使用者指南。

[cols="2,5",options="header"]
|===
|選單項目 |典型用途

|*FST4*
|LF/MF 與 HF 的弱訊號 QSO，週期較長（15 秒至 30 分鐘）。

|*FT2*
|非常快速的 77 位元模式，週期 3.75 秒（FT4 的一半）。由 WSJT-X Improved 3.1 推出。

|*FT4*
|競賽與快速 HF QSO，週期 7.5 秒。

|*FT8*
|日常的 HF/6 m 模式，週期 15 秒。也用於 DX 遠征（狐狸/獵犬）與 SuperFox。

|*JT4*
|微波 EME 以及具有都卜勒展寬的地面路徑。

|*JT9*
|HF/LF 弱訊號，週期 1 分鐘。

|*JT65*
|VHF/UHF 上的 EME 以及傳統 HF JT65。

|*Q65*
|VHF 至微波的 EME、電離層散射與雨散射。子模式 A-E，
週期 15-300 秒。與 WS-MAP 搭配使用。

|*MSK144*
|6 m 與 2 m 的流星散射。

|*FST4W*
|LF/MF 用、類似 WSPR 的信標模式，週期 2-30 分鐘。

|*WSPR*
|用於傳播研究的信標發射。回報會送到 WSPRnet。

|*Echo*
|EME 回波測試：測量您自己從月球反射回來的回波。

|**頻率校準**（FreqCal）
|電臺的頻率校準。請參閱 <<MENU_TOOLS>>。
|===

[[MENU_TOOLS]]
=== 工具

image::menu-Tools.png[工具選單]

[cols="2,5",options="header"]
|===
|選單項目 |功能

|**清除參考頻譜**
|清除正在測量的參考頻譜。

|**測量參考頻譜**
|開始**監聽**並平均接收到的音訊頻譜。按一下
**停止**即可將其儲存到 `refspec.dat`。在頻譜瀑布圖中勾選
**參考規格**，即可用此濾波器將音訊平坦化。

|**測量相位回應**
|開啟或關閉 MSK144 相位訓練。WS 會以來自
DX 呼號的解碼進行訓練，並將相位等化係數儲存到
資料目錄中的檔案。取得足夠資料後訓練會自動結束。

|**均衡工具 ...**
|開啟一個視窗，繪製測量值、建議值與目前的相位與
群延遲，以及參考頻譜。可用來載入（**相位 ...**）、
重新整理或捨棄相位等化資料。

|**執行頻率校準週期**
|在頻率校準模式中，於每個週期結束時將電臺重新調到
menu:檔案[設定 > 頻率] 中的下一個 FreqCal 頻率，讓您能
依序測量多個已知頻率的電臺。

|**修正校準參數**
|對 `fmt.all` 中的測量值擬合斜率（ppm）與截距（Hz），
並顯示結果。**Apply** 會將其儲存為您在
menu:檔案[設定 > 頻率] 中的校準值。之後可將 `fmt.all` 重新命名為 `fmt.bak`。
|===
