==== 電臺詳情

[cols="2,5",options="header"]
|===
|設定 |功能

|**我的呼號**
|您的呼號。

|**我的網格**
|您的梅登黑德（Maidenhead）網格座標，最好為 6 個字元（例如 CM87ux）。
距離與方位角都以此計算。

|**自動網格**
|允許外部程式（例如 GPS 輔助程式）變更**我的網格**。

|**IARU 分區**
|第一區：歐洲、非洲、中東、北亞。第二區：
美洲。第三區：南亞與太平洋地區。用來選擇對應的
預設頻率。

|**生成第2類複合呼號持有者的訊息**
|僅適用於附加字首或字尾不在
簡短清單中的呼號（menu:說明[型態 1 前置與後綴清單]）。選擇由哪一則
產生的訊息（Tx1、Tx3 或 Tx6）帶有您的完整呼號。
|===

==== 顯示

[cols="2,5",options="header"]
|===
|設定 |功能

|**解碼新訊息從頂部往下滾動**
|每個週期都從波段活動的頂部開始，不會捲動
離開，讓您在解碼仍在進行時也能按兩下。

|**每個解碼周期插入間隔行**
|在波段活動中的週期之間加入分隔線。

|**顯示帶有時間戳的空行**
|分隔線上也會顯示該週期的 UTC。

|**顯示距離單位為英里**
|以英里取代公里。

|**突出顯示 DX 呼號** / **突出顯示 DX 網格**
|在訊息中標示目前 QSO 對象的呼號與網格。

|**發出訊息在接收視窗顯示**
|您自己發射的訊息也會出現在接收訊息窗格中。

|**突出顯示給我們的訊息中的 RRR/RR73/73**
|讓 QSO 的結束一目瞭然。

|**顯示 DXCC, 網格與曾經通聯狀態**
|在解碼中加入國家以及新 DXCC／新網格／曾經通聯的標記。
**顏色**分頁中的突出顯示需要此選項。

|**顯示前綴而非國家或地區名稱**
|較簡短：「DL」而不是「Fed. Rep. of Germany」。

|**所有訊息皆顯示 DXCC**
|在每則訊息中加入國家，而不只是 CQ 呼叫。

|**程序字型...** / **解碼字型...**
|整個程式的字型／波段活動與接收訊息窗格的字型。
|===

==== 慣常方式

[cols="2,5",options="header"]
|===
|設定 |功能

|**啟用軟體時關閉監聽**
|WS 啟動時不進行解碼，直到您按下**監聽**。

|**開始監聽時使用上一次的頻率**
|開啟**監聽**時會回到上次監聽的頻率。
未勾選時，則保持電臺目前的頻率。

|**雙擊呼號條啟用發送**
|按兩下解碼時立即開始發射。

|**傳送 73 後關閉發送**
|發送 73 或自由文字訊息後，**啟用發送**會關閉。

|**CQ 呼叫時強制呼叫第 1**
|您呼叫 CQ 時，會勾選 **Call 1st**，讓 WS 自動回應第一個呼叫者。

|**綁定 F1-F6 功能**
|將發射訊息的 kbd:[F1]–kbd:[F6] 快捷鍵切換為競賽用的
配置（請參閱 menu:說明[鍵盤快速鍵表]）。

|**啟用甚高頻和子模式功能**
|顯示 VHF/UHF/微波的控制項（子模式、平均、Sh、自動 QSY
等）。在 HF 上請關閉：它會停用寬頻 JT65 多重解碼。

|**允許發送期間改變頻率**
|若您的電臺在發射時無法處理 CAT 指令，請取消勾選（使用異頻時常需要）。

|**EME 延遲後解碼**
|在 1 分鐘模式中延後開始解碼，以便納入延遲約
2.5 秒的 EME 訊號。

|**單獨解碼**
|適用於 JT4、JT65、Q65 與 FST4：只在接收頻率附近
（**容差**範圍內）解碼，而不搜尋整個通帶。在 JT4/JT65/Q65 中，
兩個窗格會變成**單週期解碼**與**平均解碼**。

|**調諧計時器**
|經過設定的秒數後停止**調諧**。

|**MSK144/Q65: 發送直到接收到 73**
|持續發送直到收到對方的 73，最多嘗試 10
次。對困難的 VHF/UHF/SHF QSO 很有幫助。

|**自動打開/關閉 天文數據視窗**
|當您在開啟 **EME 延遲後解碼**的情況下切換到 Q65 或 JT65 時，開啟天文資料視窗，
不再需要時則關閉。

|**kHz 輸入不帶 'k' (需要重啟)**
|在頻率欄位中，輸入「164」後按 kbd:[Enter] 表示在目前 MHz 內的 +164 kHz
（438.065 -> 438.164 MHz）。方便以數字鍵盤在 EME
頻段之間跳轉。

|**發送時將進度條變為紅色**
|讓人一眼就能看出正在發射。

|**73 發送後使用 CW 發送您的呼號** / **時間間隔**
|在每次 73 或自由文字之後／每 N 分鐘（0 = 關閉）發送 CW 呼號識別，
一律在週期中安靜的部分發送。

|**發送計時器**
|經過設定的分鐘數後，停止無人看管的發射。
|===

==== 附加功能

這些選項來自 WSJT-X Improved，WSJT-X 中並沒有。

[cols="2,5",options="header"]
|===
|設定 |功能

|**顯示美國各州**
|將網格座標對應到美國各州與加拿大各省（沒有
JTAlert 時很實用）。有些網格跨越多個州；此時會全部列出。

|**啟用等待功能**
|開啟**等待與回覆**、**等待與呼叫**與**等待與突襲**（預設）。
請參閱 <<WAIT_FEATURES>>。

|**通聯後清除DX呼號** / **通聯後清除 DX 網格**
|記錄 QSO 後清空 DX 呼號／DX 網格欄位。

|**在訊息中帶網格的顯示距離** / **在訊息中帶網格的顯示方位角**
|在每則含有效網格座標的訊息中加入距離與大圓方位角。

|**波段改變後擦除解碼** / **模式改變後擦除解碼**
|變更波段／模式時清除波段活動。

|**備用擦除按鈕行為**
|**擦除**的運作方式與 JTDX 相同：按左鍵清除波段活動，
按右鍵清除接收訊息，按兩下則兩者都清除。

|**通聯後將接收頻率設定為發射頻率**
|記錄後，接收頻率會移到您的發射頻率。

|**每分鐘監聽波段跳換**
|開啟波段跳換時，WS 通常每隔一分鐘換一次波段。
勾選此項則每分鐘換一次波段。

|**對齊 DXCC, 距離和方位**與兩個數字欄位
|將國家、距離與方位角對齊成欄。第一個欄位設定
訊息與國家之間的空格數（未勾選**對齊**時也有效），
第二個設定國家與距離/方位角之間的空格數。
|===

NOTE: 若您使用帶有附加字首或字尾的呼號，或想要
與這類電臺通聯，請閱讀 WSJT-X 使用者指南中的 __Nonstandard Callsigns__（非標準呼號）一節。
