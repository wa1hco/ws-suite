[[SETTINGS_TXMACROS]]
=== 自定義訊息

image::settings-tx_macros.png[設定，自定義訊息分頁,align="center"]

自定義訊息（Tx 巨集）是您經常發送的簡短自由文字訊息，例如 `TNX 73 GL`。
它們會出現在主視窗 **Tx5** 訊息的下拉清單中。

==== 巨集清單

[cols="2,5",options="header"]
|===
|設定 |功能

|文字欄位與**新增**
|輸入訊息後按**新增**，即可將其附加到清單中。只能輸入訊息中
允許的字元；文字會轉換為大寫。

|**刪除**
|移除選取的訊息。按右鍵 → **刪除** 的效果相同；若未選取任何訊息，
則移除游標下的訊息。

|清單
|巨集依 **Tx5** 下拉清單的順序排列。拖放即可重新排序。
按兩下訊息即可編輯。按一下、kbd:[Shift]+按一下與
kbd:[Ctrl]+按一下可選取多則訊息。
|===

NOTE: 自由文字訊息最多 13 個字元，含空格。

TIP: 您也可以在主視窗的 **Tx5** 中輸入訊息後按
kbd:[Enter]；該訊息就會加入清單。在 FT8、FT4、FST4、MSK144 與 Q65 中，
以 `$DX`（或 `$DXCALL`）開頭的訊息，發送時該字會被取代為
**DX 呼號**中的基本呼號。
