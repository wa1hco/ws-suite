[[SETTINGS_ALERTS]]
=== 警報

image::settings-alerts.png[設定，警報分頁,align="center"]

WS 可以用簡短的語音警報提示所選的解碼（「New DXCC」、
「My Call」等）。警報包含在每個 WS 安裝中，並且
一律在電腦的預設音訊裝置（通常是
喇叭）上播放。

WARNING: 音訊警報需要第二個音效裝置。您的電臺**不可**透過
預設音訊裝置連接，否則警報會被發射出去。
內建 USB 音效卡的電臺（IC-7300、FT-991 等）符合
此需求。啟用前請先測試（請參閱下方的**測試**）。

==== 音訊警報

[cols="2,5",options="header"]
|===
|設定 |功能

|**語音**
|選擇警報使用的語音。標準安裝只有一種語音：**預設值**。

|**測試**
|在預設音訊裝置上播放測試提示，讓您確認
警報從哪裡發出聲音。

|**新 DXCC** / **新 DXCC 波段**
|您尚未通聯過／尚未在目前波段通聯過的 DXCC 實體。

|**新大洲** / **新大洲 波段**
|尚未通聯過／尚未在此波段通聯過的大洲。

|**新 CQ 分區** / **新 CQ 分區 波段**
|尚未通聯過／尚未在此波段通聯過的 CQ 分區。

|**新 ITU 分區** / **新 ITU 分區 波段**
|尚未通聯過／尚未在此波段通聯過的 ITU 分區。

|**新美國州** / **新美國州 波段**
|美國 50 州中尚未通聯過／尚未在此波段通聯過的州。
州別取自呼號，或在網格只對應單一州時取自網格。

|**新網格** / **新網格 波段**
|尚未通聯過／尚未在此波段通聯過的網格座標。只計算含網格的訊息。

|**我的呼號**
|發給您的訊息。

|**DX 呼號或 DX 網格在訊息內**
|**DX 呼號**欄位中的呼號，或 **DX 網格**欄位中的網格，出現在解碼中。

|**CQ 訊息**
|任何 CQ 呼叫。

|**渴望的呼號, 網格, 前綴和定向呼叫**
|解碼符合您在**顏色**分頁中的**突出顯示橙色**或**突出顯示藍色**項目
（僅限該突出顯示開啟時），或在勾選 menu:過濾[突出顯示白名單項目] 時
符合白名單項目。

|**訊息已接收**
|收到發給您的呼號或 DX 呼號的 QSY 訊息。只有 QSY 訊息
會觸發此警報，因此很少出現。

|**啟用音訊警報**
|總開關：關閉時不會發出任何警報聲。開啟時按鈕
會變成綠色。在 Windows 上，WS 啟動時也會播放一段簡短的測試音。
|===

分隔線以上的類別需要在**一般**分頁中勾選**顯示 DXCC, 網格與曾經通聯狀態**。

警報與**顏色**分頁中的突出顯示彼此獨立運作。但
只有在該處開啟對應的突出顯示時，您才能看出是哪一筆解碼觸發了警報，
因此請在兩個分頁中啟用相同的類別。

NOTE: 忽略清單中的電臺（以 **DX 網格**下方的**忽略**按鈕加入）
除了**我的呼號**之外不會觸發任何警報，除非勾選了**繞過**（BP）
核取方塊。使用 menu:檔案[刪除忽略清單] 清除清單。

TIP: 波段跳換關閉時，在主視窗的**監聽波段跳換**按鈕上按右鍵，
可對預設音訊裝置進行較長時間的測試。
