[[SETTINGS_FILTERS]]
=== 過濾

image::settings-filters.png[設定，過濾分頁,align="center"]

過濾條件決定哪些解碼會出現在**波段活動**窗格中。此分頁中的
清單會與**過濾**選單中的快速過濾共同運作
（請參閱 <<MENU_FILTERS>>），區域過濾也是在該選單中
開啟與關閉。

當過濾條件隱藏了解碼時，主視窗左下角的狀態標籤
會從綠色的「Receiving」變成青色的「Receiving, Filters On」。

若要暫時再次看到所有內容，請勾選主視窗上的**繞過**（BP）：
所有過濾條件都會被忽略，標籤顯示「Receiving, Filters
bypassed」。取消勾選即可恢復您的過濾條件。

NOTE: 在特殊操作模式中，黑名單、白名單與始終通過會自動關閉，
以免您錯過電臺。對獵犬而言，黑名單與
白名單仍保持作用。

==== 過濾清單

[cols="2,5",options="header"]
|===
|設定 |功能

|**過濾菜單中隱藏覆選框的 1-4 區域**
|最多四個國家名稱或名稱的一部分，用於**過濾**選單中的**隱藏區域 1 的電臺** ... **4**
與**突出顯示區域 1 的電臺** ... **4** 項目；
這些選單項目隨後會顯示您輸入的文字。請依照
WS 顯示的方式填寫名稱，例如 `Japan`、`U.S.A.` 或 `Canary Is.`。

|**黑名單** +
**隱藏包含以下呼號或關鍵字的訊息:**
|隱藏含有任一項目的訊息：完整呼號、呼號的
一部分、網格或文字（例如盜播呼號或競賽訊息）。

|**白名單** +
**僅顯示包含以下呼號或關鍵字的訊息:**
|只顯示含有其中一個項目的訊息；其他訊息都會
隱藏，但始終通過清單中的除外。

|**始終通過** +
**始終通過帶有以下關鍵字的訊息:**
|含有這些項目的訊息一律顯示，即使黑名單、
白名單，或針對區域、大洲、曾經通聯電臺的隱藏項目
原本會將其隱藏。
|===

每個清單有十二個欄位，每個欄位一個項目。項目會轉換為
大寫字母。清單只有在勾選其核取方塊時才會生效。

==== 選項

[cols="2,5",options="header"]
|===
|設定 |功能

|**應用篩選僅對呼叫中的電臺呼號**
|清單只與呼叫中的電臺比對（通常是
第二個字，`CQ NA` 這類定向 CQ 則為第三個字）。此時項目
必須符合呼號的開頭，因此 `JA` 這類字首可以使用。
未勾選時，項目可符合訊息中的任何位置。

|**為 等待和突襲, CQ:第一, 等使用篩選. 僅 (仍顯示所有訊息)**
|**波段活動**中不會隱藏任何內容；過濾條件只決定
等待與突襲以及 **CQ:** 選項要回應哪些電臺。請參閱 <<WAIT_FEATURES>>。

|**快速篩選: 隱藏/忽略/突出顯示 "今天和昨天曾通聯" 而不是 "今天曾通聯" (UTC)**
|**過濾**選單中的三個「今天已通聯」項目也會包含
昨天（UTC）通聯過的電臺。
|===
