==== 頻率校準

[cols="2,5",options="header"]
|===
|設定 |功能

|**傾斜率** / **攔截**
|修正電臺已知的刻度誤差： +
`rig frequency = Intercept + (1 + Slope / 1 000 000) × f` +
其中**攔截**（截距）以 Hz 為單位，**傾斜率**以 ppm 為單位。傳送到電臺以及
從電臺讀回的頻率都會經過修正，因此 WS 會顯示真實頻率。若您的電臺很準確，
兩者都保持為 0 即可。
|===

TIP: 如何測量這些數值，請參閱 WSJT-X 使用者指南中的 __Frequency Calibration__
（頻率校準，FreqCal 模式）。

==== 工作頻率

主視窗波段選擇器中提供的頻率。WS 只顯示
符合您的 **IARU 分區**（**一般**分頁）與目前模式的項目。
按兩下儲存格即可編輯。

[cols="2,5",options="header"]
|===
|欄位 |功能

|**IARU 分區** / **模式**
|此項目在何處、針對何種模式提供。設為**全部**的項目
在所有地區／所有模式中都會提供。

|**頻率**
|刻度頻率，單位為 MHz。

|**優先**
|該波段與模式的偏好項目。當您按下波段按鈕
（menu:顯示[]）或 WS 自行切換波段（波段跳換）時會使用它。每個
波段與模式只能有一個偏好項目。

|**描述**
|您為此項目自訂的標籤，會顯示在波段選擇器中。

|**開始日期和時間** / **結束日期/時間**
|此項目只在這段期間內提供，例如用於 DX 遠征。空白 = 一律提供。
|===

在表格上按右鍵可執行下列操作：

[cols="2,5",options="header"]
|===
|選單項目 |功能

|**刪除**
|移除選取的項目。

|**插入 ...**
|新增項目：**IARU 分區**、**模式**、**頻率 (兆赫)**、**首選波段/模式**、
**描述**以及選用的日期範圍。

|**載入...**
|以 `.qrg` 或 `.qrg.json` 檔案中的清單取代目前清單（WS 會先詢問）。

|**另存為 ...**
|將清單儲存到檔案；檔名以 `.qrg.json` 結尾時會產生 JSON 檔案。
若有選取項目，WS 會詢問是否只儲存這些項目。

|**合併 ...**
|將 `.qrg` 或 `.qrg.json` 檔案中的項目加入清單。

|**重置**
|還原預設清單（WS 會先詢問）。
|===

==== 電臺相關資料

各波段的電臺詳細資料。按兩下儲存格即可編輯。

[cols="2,5",options="header"]
|===
|欄位 |功能

|**波段**
|此列適用的波段。

|**偏移**
|加到顯示頻率上以得到電臺頻率，用於
轉頻器（transverter）。例如：使用 28 MHz 中頻的 144 MHz 需要 -116 MHz。預設為 0。

|**天線描述**
|您在此波段時傳送給 PSK Reporter。
|===

在表格上按右鍵可使用**刪除**（移除選取的列）與
**插入 ...**（新增一列：**波段**、**偏移 (MHz)**、**天線**）。

TIP: 若要快速建立各列，請在**工作頻率**中選取項目（按 kbd:[Ctrl]+kbd:[A]
全選），並將其拖放到**電臺相關資料**上。然後再填入偏移與
天線。
