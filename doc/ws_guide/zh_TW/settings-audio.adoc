==== 聲卡

[cols="2,5",options="header"]
|===
|設定 |功能

|**輸入** / **輸出**
|連接到電臺的音效卡（例如電臺的 USB 音訊 CODEC），
設定為 48000 Hz、16 位元。右側欄位用來選擇聲道：
通常為**單聲道**，特殊設置時則為**左聲道**、**右聲道**或**雙聲道**。

|**更新**
|重新載入裝置清單，例如在插入 USB 電臺之後。

|**使用 TCI 音頻 (需要重新啟動)** / **接收** 0 dB
|只有使用 TCI 電臺（例如 SDR）時才會顯示。此時音訊會透過
TCI 連線傳送，而不是經由音效卡，裝置欄位會顯示 **TCI audio**。
**接收**會降低接收音訊電平（0 至 -50 dB）。變更後請重新啟動 WS。

|**按字母順序排序**
|依字母順序排列裝置名稱，且只列出能夠
錄製或播放 PCM 音訊的裝置。未勾選時，則使用系統順序。

|**隱藏 ALSA 音效卡子設備 (僅 Linux)**
|隱藏通常無法使用的 `CARD=` 項目。只有在勾選
**按字母順序排序**時才有效。
|===

IMPORTANT: 若輸出裝置同時也是電腦的預設音效
裝置，請關閉所有系統音效。否則它們會被您發射到空中。

==== 儲存資料夾

[cols="2,5",options="header"]
|===
|設定 |功能

|**資料夾位置** / **選擇**
|menu:儲存[] 所寫入之 `.wav` 檔案的資料夾。預設為日誌目錄中的 `save`
資料夾。
|===

==== AzEl 資料夾

[cols="2,5",options="header"]
|===
|設定 |功能

|**位置** / **選擇**
|`azel.dat` 所在的資料夾，此檔案包含太陽與月球的位置及都卜勒資料，供
天線追蹤程式使用。天文資料視窗開啟期間，
每秒更新一次。

|**為 azel.dat 啟用額外的行**
|加入一行 Dpol、MNR、Dgrd 與回波寬度，供會讀取這些數值的
追蹤程式使用。
|===

==== 按波段記憶設定功率

[cols="2,5",options="header"]
|===
|設定 |功能

|**發送**
|記住每個波段的**功率**滑桿位置，並在您切換波段時還原。

|**調諧**
|為**調諧**另外保留每個波段的**功率**設定。調諧結束時，
滑桿會回到您的發射功率。
|===
