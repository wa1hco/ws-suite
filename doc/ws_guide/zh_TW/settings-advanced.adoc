==== JT65 VHF/UHF/Microwave 解碼參數

[cols="2,5",options="header"]
|===
|設定 |功能

|**隨機清除模式**
|JT65 軟判決解碼器嘗試的程度（最多 10^n/2^ 種模式）。
數值越高靈敏度略高但速度較慢；6 或 7 適合大多數電臺。

|**主動解碼等級**
|JT65 深度搜尋的門檻值（0–10）。等級越高解碼越多，
但錯誤解碼也越多。

|**使用二次解碼**
|JT65：在減去第一次解碼找到的訊號後，
再進行第二次解碼。
|===

==== 高解析度顯示器的用戶界面調整

[cols="2,5",options="header"]
|===
|設定 |功能

|**高 DPI 縮放 (需要重啟)**

|===

==== 雜項

[cols="2,5",options="header"]
|===
|設定 |功能

|**降低訊噪比的 .wav 檔案** / **接收頻寬**
|用於離線靈敏度測試：在您開啟的 .wav 檔案中加入雜訊，將
S/N 降低指定的 dB 數。請將**接收頻寬**設為您接收機的雜訊
頻寬，使數值準確。

|**發射延遲**
|從 PTT 到開始發射音訊之間的最短時間（0 至 0.5 秒）。FT4 與
FT2 一律使用 20 ms。

|**音調間距**：**x 2** / **x 4**
|兩倍／四倍的正常音調間距，適用於將頻率除以 2 或 4 的
LF/MF 發射機。兩者只能勾選其一。

|**瀑布頻譜**：**低側邊** / **最敏銳**
|**低側邊**（預設）使用加窗 FFT，讓強訊號在瀑布圖上
擴散得較少。**最敏銳**不使用窗函數，能稍微更清楚地顯示非常
微弱的訊號軌跡。
|===

IMPORTANT: **發射延遲**無法取代硬體時序控制器。為了保護
收發繼電器與前置放大器，請使用時序控制器，並測試時序是否正確。

==== 特殊操作活動

勾選此方塊並選擇一項活動；WS 便會產生對應的
訊息格式。

[cols="2,5",options="header"]
|===
|設定 |功能

|**NA VHF**
|北美 VHF/UHF/微波競賽，以及其他以 4 字元
網格作為交換資料的競賽。

|**NCCC Sprint**
|僅搭配 **NA VHF**：FT4（及 FT2）用的 NCCC Sprint 短訊息協定。

|**EU VHF Contest**
|歐洲 VHF 以上頻段競賽：報告、流水號與 6 字元網格座標。

|**WW Digi Contest** / **ARRL Digi Contest**
|World-Wide Digi 競賽／ARRL International Digital Contest。

|**Q65 堆叠**
|交換 4 字元網格座標而非報告，讓 DX 操作員
獲得 q3 等級的靈敏度。特別適合 6 m EME DX 遠征。

|**ARRL Field Day** / **FD 交換**
|您的交換資料：發射機數量、類別與 ARRL/RAC 分區，或「DX」
（例如 `6A SNJ`）。

|**FT Roundup messages** / **FT RU 交換**
|FT Roundup 及類似競賽。交換資料：美國州名、加拿大省名或
「DX」（阿拉斯加與夏威夷也使用 DX）。

|**狐狸** / **獵犬**
|FT8 DX 遠征模式：**狐狸**用於 DX 遠征隊，**獵犬**用於呼叫它。使用前
請先閱讀 FT8 DX 遠征模式使用者指南。

|**超級狐狸模式**
|搭配**狐狸**或**獵犬**：發射或接收 SuperFox 波形。

|**OTP** / **密鑰** / **間隔**
|搭配**狐狸**或**獵犬**：以一次性密碼驗證狐狸（需要
網際網路）。狐狸輸入其 16 個字元的**密鑰**，並每隔**間隔**則
訊息簽署一次（1 = 每則訊息）。

|**顯示 OTP 訊息** / **OTP 網址**
|供獵犬使用：WS 會在 **OTP 網址**（預設為
`https://www.9dx.cc`）檢查狐狸的代碼。**顯示 OTP 訊息**會在波段活動中顯示驗證
訊息。

|**CQ 單獨競賽名稱** / **競賽名稱**
|呼叫例如 `CQ PACC`，而不是 CQ TEST、RU 或 WW。使用
**狐狸**、**獵犬**或 **Q65 堆叠**時無法使用。
|===

==== 上傳 QSO 至 Cloudlog 或 Wavelog

[cols="2,5",options="header"]
|===
|設定 |功能

|**上傳 QSO 至 Cloudlog 或 Wavelog**
|勾選群組標題，即可將每筆已記錄的 QSO 傳送到您的 Cloudlog 或
Wavelog 伺服器。

|**API 網址**
|您安裝的基本位址，結尾不加斜線
（例如 `https://log.example.com`）。

|**API 密匙** / **電臺 ID**
|具寫入權限的 API 金鑰，以及 Cloudlog/Wavelog 中的電臺設定檔 ID。

|**測試 API 密匙**
|以試執行（dry-run）模式傳送測試 QSO。金鑰可寫入時按鈕變成綠色，
唯讀時變成橘色，無效時變成紅色。
|===

==== 上傳 QSO 至 eQSL.cc

[cols="2,5",options="header"]
|===
|設定 |功能

|**上傳 QSO 至 eQSL.cc**
|勾選群組標題，即可將每筆已記錄的 QSO 上傳到 eQSL.cc。

|**使用者名稱** / **密碼**
|您的 eQSL.cc 登入資料。

|**QTH**
|若您在 eQSL.cc 上有多個 QTH，請填入 QTH 暱稱。
|===

NOTE: eQSL.cc 密碼與 API 金鑰以未加密的方式儲存在
設定檔中。
