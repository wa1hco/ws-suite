== Guía del usuario de WS

[preface]
== Acerca de esta guía

WS es un conjunto de programas para la comunicación digital con señales
débiles en radioafición: *WS* (el programa principal), *WS-MAP* (monitor
de banda ancha para Q65/FT8) y *EME65* (JT65/Q65 de banda ancha para EME).
WS nació de _WSJT-X_ y antes se llamaba _WSJT-X Improved_. Todos los modos y los
procedimientos básicos de operación son los mismos que en WSJT-X; para ellos,
la https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-3.0.0-rc1.html[Guía del usuario de WSJT-X]
sigue siendo la referencia.

Esta guía es breve a propósito. Explica cada menú y cada ajuste de WS,
y lo que WS añade a WSJT-X.
