== WS felhasználói kézikönyv

[preface]
== A kézikönyvről

A WS gyengejeles digitális amatőrrádiós összeköttetésekhez készült
programcsomag: *WS* (a főprogram), *WS-MAP* (szélessávú Q65/FT8 monitor)
és *EME65* (szélessávú JT65/Q65 EME-hez). A WS a _WSJT-X_-ből nőtt ki, és
korábban _WSJT-X Improved_ néven volt ismert. Minden üzemmód és az alapvető
üzemi eljárások megegyeznek a WSJT-X-éivel; ezekhez továbbra is a
https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-3.0.0-rc1.html[WSJT-X User Guide]
a referencia.

Ez a kézikönyv szándékosan rövid. Bemutatja a WS minden menüjét és minden
beállítását, valamint azt, amit a WS a WSJT-X-hez képest hozzáad.
