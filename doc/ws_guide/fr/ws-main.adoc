== Guide utilisateur WS

[preface]
== À propos de ce guide

WS est une suite de programmes pour les communications numériques à signaux
faibles en radioamateur : *WS* (le programme principal), *WS-MAP* (moniteur
large bande Q65/FT8) et *EME65* (JT65/Q65 large bande pour l'EME). WS est issu
de _WSJT-X_ et s'appelait auparavant _WSJT-X Improved_. Tous les modes et les
procédures de trafic de base sont les mêmes que dans WSJT-X ; pour ces sujets, le
https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-3.0.0-rc1.html[Guide utilisateur WSJT-X]
reste la référence.

Ce guide est volontairement court. Il explique chaque menu et chaque
paramètre de WS, ainsi que ce que WS ajoute à WSJT-X.
