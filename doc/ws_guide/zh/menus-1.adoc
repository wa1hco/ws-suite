[[MENU_FILE]]
=== 文件

image::menu-File.png[文件菜单]

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**打开文件** kbd:[Ctrl+O]
|停止 **监听** 并打开录制的 `.wav` 文件，然后像实时音频一样
对其解码。

|**打开下一个文件**
|打开并解码同一文件夹中的下一个 `.wav` 文件。

|**打开余下文件** kbd:[Shift+F6]
|依次打开并解码文件夹中后续所有 `.wav` 文件。

|**删除所有在 SaveDir 目录内 {asterisk}.wav & {asterisk}.c2 文件**
|确认后，删除保存目录中所有已保存的音频文件（`.wav` 和 `.c2`）。

|**删除 ALL.TXT**
|确认后，删除 `ALL.TXT`，即你接收和发射的所有内容的
记录。

|**删除通联日志 wsjtx_log.adi**
|确认后，删除你的 ADIF 日志文件。

|**删除 wsjtx.log**
|确认后，删除 `wsjtx.log`，即由 **记录通联** 写入的简单 QSO 列表。
WS 用它实现 "worked today" 过滤，并使
**等待和突袭** 不去呼叫你已记录过的电台。

|**删除忽略列表**
|确认后，清空忽略列表（通过 **忽略** 按钮填入）。

|**擦除 WSPR 哈希表**
|确认后，删除 WSPR 用于解析哈希复合呼号的
表。

|**清除 Q65 呼叫者列表**
|确认后，删除 WS 从 Q65 解码中记住的
呼号列表。

|**重置 Cabrillo 日志 ...**
|确认后，从竞赛日志中删除当前竞赛的所有 QSO。
它们仍保留在 ADIF 日志中，但不能再导出
为 Cabrillo。流水号重新从 1 开始，
**活动电台** 中的得分也会重置。

|**导出 Cabrillo 日志 ...**
|将竞赛日志保存为 Cabrillo 文件以便提交。

|**打开日志文件目录**
|在文件管理器中打开 WS 数据文件夹（日志、`ALL.TXT` 等）。

|**设置...**
|打开 **设置** 窗口（也可按 kbd:[F2]）。见设置一章。

|**关闭软件**
|关闭 WS。
|===

NOTE: 在 macOS 上，**设置**（显示为 **Preferences**）和 **关闭软件**（显示为 **Quit**）
位于应用程序菜单中，而不在 **文件** 菜单中。

[[MENU_CONFIGURATIONS]]
=== 配置

image::menu-Config.png[配置菜单]

__配置__ 是一组完整的、带名称的设置。许多操作员
为每种模式或每种电台配置各保留一个（例如 "FT8 HF" 和
"Q65 EME"），点击两次即可切换。

菜单列出所有配置；正在使用的配置带有勾选标记。每个
配置都会打开一个小子菜单（左：其他配置，
右：正在使用的配置）：

image:menu-Config-Other.png[其他配置的子菜单] image:menu-Config-Current.png[正在使用的配置的子菜单]

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**切换到**
|WS 以该配置的设置重新启动主窗口。
正在使用的配置不显示此项。

|**克隆**
|生成一个名为 "__name__ - Copy" 的副本。重命名并调整其设置，
即可创建新配置。

|**克隆到 ...**
|用你选择的另一个配置的设置覆盖此配置的全部设置。
会要求确认。仅在存在多个配置时
显示。

|**重置**
|确认后，将此配置恢复为默认值。

|**重新命名 ...**
|为配置指定新名称。

|**删除**
|确认后，删除该配置。正在使用的配置
不能删除，因此不会为它显示此项。
|===

TIP: 要直接以某个配置启动 WS，请使用命令行选项
`--config NAME`（或 `-c NAME`），例如 `ws -c Echo`。

[[MENU_VIEW]]
=== 显示

image::menu-View.png[显示菜单]

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**瀑布图**
|打开带频谱和瀑布图的频谱瀑布图窗口。

|**天文数据**
|打开（勾选）或关闭天文数据窗口：月亮和太阳
数据、EME 多普勒频移、多普勒跟踪和约定（sked）频率。

|**信息平均值** kbd:[F7]
|打开信息平均值窗口，显示用于
平均解码的周期（JT4、JT65、Q65）。

|**Echo 图** kbd:[F8]
|打开用于 Echo 模式的 Echo 图窗口。

|**快速图** kbd:[F9]
|打开用于快速模式（MSK144 和快速 JT9）的快速图窗口。

|**竞赛日志**
|显示当前竞赛的 QSO 及其数量。

|**狐狸日志**
|显示在 FT8 DX 远征模式中作为狐狸完成的 QSO。

|**颜色突出显示设定**
|当前解码突出显示颜色的小图例（CQ、我的呼号、
新 DXCC、LoTW 用户等）。颜色在 **颜色**
设置选项卡上设置。

|**活动电台**
|列出最近解码到的电台，例如在按距离计分的竞赛中找出最远的
电台，并显示 **比率**、**分数** 和 **波段变换**。
点击某一行即可呼叫该电台。运行 WS-MAP 时，它会显示
WS-MAP 在其整个带宽内解码到的电台；单击
将 QSO 数据和约定频率传给 WS，双击则呼叫
该电台。

|**SWL模式**
|隐藏下方的控制面板，让解码区域占据整个窗口。
同时运行多个实例时很有用。此视图的大小和位置
单独记忆。

|**信息创建器**
|编写特殊信息，例如请求 QSY 到其他波段或模式，
或简短的预设信息，发送给 **DX 呼号** 中的电台。打开
它时也会开启 **启用信息弹出窗口**。

|**QSY监听**
|显示其他电台相互之间以及发给你的特殊信息。

|**启用信息弹出窗口**
|有发给你的特殊信息时出现弹出窗口，其中
有用于回复的按钮。

|**波段按钮**
|显示一排 HF 波段按钮（160 m 至 70 cm）；当前波段为
绿色。点击按钮即可转到该波段和模式的首选频率
（在 **频率** 设置选项卡上用 **优先** 设置）。
右键点击 80 m 至 10 m（FT8、FT4、FT2）转到常用的 DX 远征
频率，右键点击 6 m（FT8）转到 50.323 MHz。另见
menu:帮助[特殊鼠标命令表]。

|**VHF / UHF 按钮**
|用一组 VHF/UHF/微波按钮（8 m 至 24 GHz）替换 HF 按钮。
仅在勾选 **波段按钮** 时可见。

|**启用黑夜模式**
|将所有窗口切换为深色主题。它不只是简单的深色
样式表：WS 还会调整一些内部设置，并使用为此
优化的样式表。之后请在 **颜色** 设置选项卡上将突出显示颜色
改为较柔和的粉彩色调。

|**瀑布上的呼号**
|子菜单，见下文。
|===

==== 瀑布上的呼号

image::menu-View-Callsign_overlay.png[瀑布上的呼号子菜单]

WS 可以将解码到的呼号直接写在瀑布图上，位于
听到每个电台的频率处。

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**显示已解码呼号**
|开启或关闭呼号标签。关闭时会移除所有标签。
打开 `.wav` 文件也会清除它们。

|**保留 1 个周期** ... **保留 5 个周期**
|电台最后一次被解码后标签保留的时间，以
收发周期计（默认 2）。同一数值也可以在频谱瀑布图窗口中设置。

|**字体大小**
|image:menu-View-Callsign_overlay-Callsign_font.png[字体大小子菜单] +
标签大小：**小 (7 pt)**、**正常 (8 pt)**、**中 (10 pt)** 或 **大 (12 pt)**。

|**透明度**
|image:menu-View-Callsign_overlay-Callsign_transparency.png[透明度子菜单] +
瀑布图透过标签显示的程度：**无**、**低**、**中等** 或 **高**。

|**位置**
|image:menu-View-Callsign_overlay-Callsign_position.png[位置子菜单] +
**瀑布顶部**，或 **瀑布底部 (分隔线上方)**，使顶部
最新的信号不被遮挡。
|===

[[MENU_SAVE]]
=== 保存

image::menu-Save.png[保存菜单]

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**不保存**
|不保存任何音频文件。

|**保存解码**
|将每个至少有一条解码的周期的音频（`.wav`）保存到
保存目录中。

|**保存所有文件**
|保存每个周期的音频。

|**30天后删除保存的文件**
|每次程序启动时，WS 删除保存目录中所有
超过 30 天的文件。

|**不分拆 ALL.TXT**
|所有解码和发射都写入同一个 `ALL.TXT`（默认）。

|**分拆每年 ALL.TXT**
|每年一个文件，例如 `2026-ALL.TXT`。

|**分拆每月 ALL.TXT**
|每月一个文件，例如 `2026-09-ALL.TXT`。

|**禁止写入 ALL.TXT**
|不向 `ALL.TXT` 写入任何内容。

|**默认事件记录**
|正常、最少的内部日志记录。同时会再次关闭 **诊断模式**。

|**诊断模式**
|收集详细数据，用于排查 WS 或其与电台通信方面的
问题。重启后生效，并在下次关闭
WS 时自动关闭。桌面上会出现一个 `logs` 文件夹，其中有
`ws_syslog.log` 和 `WS_RigControl.log`；如开发人员需要，请将它们发送过去。
故障出现后请尽快关闭 WS，因为这些文件增长很快。

|**禁用事件记录**
|关闭内部事件日志记录。
|===

[[MENU_LANGUAGE]]
=== 语言

image::menu-Language.png[语言菜单]

选择 WS 用户界面的语言。默认为英语；
其他条目是 WS 自带的翻译，每项都以
其本身的语言显示。

选择语言后，WS 会询问是否立即重启其窗口：

[cols="2,5",options="header"]
|===
|按钮 |功能

|**立即重启**
|在几秒钟内以新语言重建主窗口，
方式与切换到另一个配置相同。WS 本身保持运行。
WS 正在发射或调谐时不会重启窗口；新
语言将在下次启动 WS 时生效。

|**稍后**
|保留当前语言，直到再次启动 WS。
|===

该选择适用于所有配置。使用
`--language <code>` 启动 WS（例如 `ws --language de`）可在
本次运行中覆盖该选择。

NOTE: 翻译由志愿者完成，可能不完整；尚未
翻译的文本以英语显示。
