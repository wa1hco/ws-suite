[[SETTINGS_FILTERS]]
=== 过滤

image::settings-filters.png[设置 - 过滤选项卡,align="center"]

过滤决定哪些解码显示在 **波段活动** 区域中。此
选项卡上的列表与 **过滤** 菜单中的快速过滤配合使用
（见 <<MENU_FILTERS>>），区域过滤也在该菜单中
开启和关闭。

当过滤隐藏了解码时，主窗口左下角的状态标签
从绿色的 "接收" 变为青色的 "Receiving, Filters On"。

如需暂时查看全部内容，请勾选主窗口上的 **绕过**：
所有过滤都被忽略，标签显示 "Receiving, Filters
bypassed"。取消勾选即可恢复你的过滤。

NOTE: 在特殊操作模式下，黑名单、白名单和总是通过会自动
关闭，以免你错过电台。对于猎犬，黑名单和
白名单仍然有效。

==== 过滤列表

[cols="2,5",options="header"]
|===
|设置 |功能

|**Territories 1-4**
|最多四个国家/地区名称或名称的一部分，用于 **过滤** 菜单中的
**隐藏区域 1 的电台** 至 **隐藏区域 4 的电台** 以及 **突出显示区域 1 的电台** 至 **突出显示区域 4 的电台** 菜单项；
菜单项随后会显示你输入的文本。请按
WS 显示的方式书写名称，例如 `Japan`、`U.S.A.` 或 `Canary Is.`。

|**黑名单** +
**隐藏包含以下呼号或关键字的信息**
|隐藏包含任一条目的信息：完整呼号、呼号的
一部分、网格或词语（例如盗用呼号或竞赛信息）。

|**白名单** +
**仅显示包含以下呼号或关键字的信息**
|只显示包含其中某个条目的信息；其他信息全部
隐藏，总是通过列表中的除外。

|**总是通过** +
**总是通过带有以下关键字的讯息**
|含有这些条目的信息始终显示，即使黑名单、
白名单，或针对区域、大洲或曾经通联电台的隐藏菜单项
本应隐藏它们。
|===

每个列表有十二个字段，每个字段一个条目。条目会转换
为大写字母。只有勾选列表的复选框时，该列表才起作用。

==== 选项

[cols="2,5",options="header"]
|===
|设置 |功能

|**应用过滤仅对呼叫中的电台呼号**
|列表只与呼叫方电台进行比对（通常是
第二个词，对于 `CQ NA` 这样的定向 CQ 则是第三个词）。此时条目
必须与呼号的开头匹配，因此 `JA` 这样的前缀可以使用。
不勾选时，条目与信息中任意位置匹配。

|**為 等待和突袭, CQ:第一, 等使用过滤. 仅 (仍显示所有信息)**
|**波段活动** 中不隐藏任何内容；过滤只决定等待和突袭以及
**CQ:** 选项会应答哪些电台。见 <<WAIT_FEATURES>>。

|**快速过滤: 隐藏/忽略/突出显示 "今天和昨天曾通联" 而不是 "今天曾通联" (UTC)**
|**过滤** 菜单中三个 "今日已通联" 菜单项也包括
昨天（UTC）通联过的电台。
|===
