[[SETTINGS_TXMACROS]]
=== 自定义文字

image::settings-tx_macros.png[设置 - 自定义文字选项卡,align="center"]

发射宏是你经常发送的简短自由文本信息，例如 `TNX 73 GL`。
它们出现在主窗口 **Tx5** 信息的下拉列表中。

==== 宏列表

[cols="2,5",options="header"]
|===
|设置 |功能

|文本框和 **添加**
|输入信息并点击 **添加** 将其追加到列表中。只能输入
信息中允许的字符；文本会转换为大写。

|**删除**
|删除所选信息。右键点击 → **删除** 作用相同；如果
未选择任何内容，则删除光标下的信息。

|列表
|宏按 **Tx5** 下拉列表中的顺序排列。拖放即可重新排序。
双击信息可进行编辑。点击、kbd:[Shift]+点击和
kbd:[Ctrl]+点击可选择多条信息。
|===

NOTE: 自由文本信息最多 13 个字符（含空格）。

TIP: 也可以在主窗口的 **Tx5** 中输入信息并按
kbd:[Enter]；它会被添加到列表中。在 FT8、FT4、FST4、MSK144 和 Q65 中，
以 `$DX`（或 `$DXCALL`）开头的信息在发送时，该词会被替换为
**DX 呼号** 中的基本呼号。
