==== 解码突出显示

WS 按类别为解码着色。除 **CQ 信息**、
**我的信息**、**发射信息** 和 **LoTW 用户** 外，其他类别都需要在 **常规** 选项卡上开启
**显示 DXCC, 网格和曾经通联状态**。

[cols="2,5",options="header"]
|===
|设置 |功能

|突出显示列表
|每个类别一行；其复选框用于开启该类别。上下拖动行
以设置优先级：位置较高的行优先。前景色和背景色
分开处理，因此 "未设置" 的颜色取自下方下一个已启用的行。

|右键菜单
|**字体颜色 ...** / **底色 ...** 选择颜色，
**清除字体颜色** / **未设置背景颜色** 清除颜色。
**将此项重置为默认值** 将该行恢复为 WSJT-X 默认值。

|**CQ 信息**、**我的信息**、**发射信息**
|CQ、CQDX 和 QRZ 呼叫；发给你的解码；你发送的信息。

|**新DXCC**、**新大洲**、**新 CQ 分区**、**新 ITU 分区**、**新美国州**、**新网格**、**未曾通联过**
|尚未在你的日志中。**... 波段** 变体：在当前波段上
尚未通联过。

|**LoTW 用户**
|该电台在
<<LOTW_VALIDATION,LoTW 已验证用户>> 中设定的时限内向 LoTW 上传过日志。

|**将突出显示重置为 WSJT-X 默认值**
|WSJT-X 原有的颜色和顺序。新安装时使用这些设置。

|**将突出显示重置为 WS 默认值**
|WS 配色方案，使用同样适合深色样式的粉彩色。LoTW
用户显示为黑色，其他电台显示为深红色；已经通联过的电台
发出的 CQ 使用灰色背景。

|**重新扫描 ADIF 日志**
|重新读取 `wsjtx_log.adi` 并重建曾经通联状态。
按钮显示 QSO 数量。可以用日志程序导出的 ADIF 文件
替换该文件。

|**按模式突出显示**
|曾经通联状态按模式分别保存。

|**仅寻求网格字段**
|只有当网格的大区（前两个字符，例如 JO）
尚未通联过时，该网格才算新网格。

|**包括额外的 WAE 实体**
|以其本身的名称显示额外的 DARC WAE / CQ Marathon 实体（例如 Sicily、Shetland Is.）。
不勾选时，它们显示为所属的 DXCC 国家/地区。

|**突出显示 73 或 RR73 信息**
|73 和 RR73 信息像 CQ 一样突出显示，并带有国家/地区和
曾经通联标记。它们也能通过 **仅显示CQ** 过滤，此时该过滤
显示为 **CQ/73**。默认开启。

|**突出显示所有信息**
|每条解码信息都像 CQ 一样突出显示，并带有国家/地区和
曾经通联标记，而不仅限于 CQ 呼叫（以及开启上一选项时的 73 信息）。默认关闭。

|**突出显示橙色:** / **突出显示蓝色:**
|对下方框中输入的呼号、网格、
前缀和 CQ 方向，以橙色 / 蓝色背景白色文字显示。这些条目也会
触发 **警报** 选项卡上的 **渴望的呼号, 网格, 前缀和定向呼叫** 警报。
|===

**突出显示橙色** 和 **突出显示蓝色** 的条目（大小写均可）：

* 呼号：每个呼号后加逗号，最后一个也要加：`K1JT, DG2YCB,`
* 网格：`JO33, JN58,`
* 2 或 3 个字符的前缀，放在分号之间：`;DL;KH6;`。单字母
  前缀如 `;K;` 只匹配第二位是数字的呼号
  （K1ABC，而非 KH6ABC）。
* 以某个字母开头的所有呼号：`;K*;`。将要排除的前缀放在
  感叹号之间即可排除：`;K*;!KH6!KL!KP!`
* CQ 方向，前后各加一个逗号：`,EU,` 标记 "CQ EU ..."。

[[LOTW_VALIDATION]]
==== LoTW 已验证用户

[cols="2,5",options="header"]
|===
|设置 |功能

|**用户 CSV 文件 网址** / **立即获取**
|ARRL 的 LoTW 用户及其最后上传日期列表的来源。
**立即获取** 下载最新副本。仅当
文件不存在且 **LoTW 用户** 突出显示开启时，WS 才会自行获取。

|**上次上传的时间早于以下时间**
|只有最后一次上传在此时限之内的电台才算作 LoTW 用户。
|===

==== 下载

[cols="2,5",options="header"]
|===
|设置 |功能

|**下载最新的 CTY.dat**
|从 country-files.com 更新国家/地区、分区和前缀数据，并
重新扫描日志。**CTY 文件版本** 显示正在使用的版本。

|**下载美国呼号所属州数据库**
|用于 **显示美国州**（**常规** 选项卡）的呼号到州数据，在
信息中没有可用网格时使用。**呼号所属州数据库** 显示其大小和日期。

|**下载 CALL3.TXT 供 IARU 分区使用** / **下载 CALL3.TXT 供 EME 使用**
|用于 **查找** 按钮以及 JT4/JT65 深度搜索的呼号和网格数据库；
EME 版本专用于 JT65 深度搜索。之前的文件
保留为 `CALL3_backup.TXT`。**CALL3 文件版本** 显示版本。
|===
