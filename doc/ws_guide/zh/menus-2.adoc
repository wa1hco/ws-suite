[[MENU_FILTERS]]
=== 过滤

image::menu-Filters.png[过滤菜单]

用于波段活动区域的快速过滤。它们使用的列表（忽略
列表、白名单、区域）在 menu:文件[设置 > 过滤] 中设置，
见 <<SETTINGS_FILTERS>>。所有过滤均可组合使用。主窗口上的
**绕过** 复选框只需点击一次即可绕过它们。**隐藏** 过滤开启时，
状态标签变为青色并显示 "Receiving, Filters On"
（勾选 **绕过** 时为绿色的 "Receiving, Filters bypassed"）。

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**隐藏在波段上曾经通联的呼号**
|隐藏当前波段上已在你日志中的呼号发出的信息。

|**隐藏今天或昨天曾经通联的呼号**
|隐藏你今天（或昨天）记录过的呼号。除非 **过滤** 选项卡上
的相应选项加入了昨天，否则此项显示为
"隐藏今日已通联的电台"。

|**从忽略列表中隐藏呼号**
|隐藏忽略列表中的呼号。**忽略** 按钮会将 DX 呼号
加入该列表；可在 **文件** 菜单中删除该列表。

|**忽略在这波段上曾经通联的电台**
|这些电台仍然可见，但 WS 不会自动应答它们
（CQ: First / Max Dist / Max dB / Min dB、等待和突袭、等待和回复）。

|**忽略今天或昨天曾经通联的呼号**
|同上，适用于今天（或昨天）记录过的呼号。

|**从忽略列表中忽略呼号**
|同上，适用于忽略列表中的呼号。

|**隐藏区域 1 的电台** ... **4**
|隐藏国家/地区名称中包含为该区域输入的文本的电台。
输入区域后，菜单项会显示其名称
（例如 "隐藏 Italy 的电台"）。

|**隐藏 欧洲 的电台**、**北美洲**、**南美洲**、**亚洲**、
**非洲**、**大洋洲**、**南极洲**
|隐藏该大洲的所有电台。便于只显示 DX。

|**突出显示在波段曾经通联的呼号**
|本波段已通联过的呼号使用灰色背景。

|**突出显示今天或昨天曾经通联的呼号**
|今天（或昨天）记录过的呼号显示为深灰底黄字。

|**从忽略列表中突出显示呼号**
|忽略列表中的呼号显示为深红底黄字。

|**突出显示区域 1 的电台** ... **4**
|来自该区域的呼号使用紫色背景。

|**突出显示白名单条目**
|包含白名单条目的呼号使用品红色背景。
白名单过滤本身不必开启。
|===

[[MENU_DECODE]]
=== 解码

image::menu-Decode.png[解码菜单]

WS 只显示适用于当前模式的菜单项。部分菜单项需要
**启用甚高频和子模式功能**（menu:文件[设置 > 常规]）。

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**快速**
|解码最快，灵敏度最低。

|**正常**
|中等深度。

|**深度**
|灵敏度最佳，速度较慢，错误解码的几率略高。
在 Echo、频率校准以及启用 VHF 功能的 JT65 中为灰色不可用。

|**使用多线程 FT8 解码器**
|仅限 FT8。并行运行多个解码线程。在繁忙的波段上
通常能得到更多解码。对于极弱信号通信，
单线程的 **深度** 解码器往往更好。在 **参数** 下进行配置。

a|**参数**

image::menu-Decode-Parameters.png[解码 - 参数子菜单]
a|多线程 FT8 解码器的微调。除非开启
**使用多线程 FT8 解码器**，否则不起作用。

[cols="2,5"]
!===
!**线数量** +
image:menu-Decode-Parameters-FT8_threads.png[线数量]
!**自动**（默认）会留出一些核心：2-4 个逻辑核心时
少用一个，5-8 个时少用两个，9-15 个时少用三个，16 个
或更多时使用 12 个。**1**-**12** 直接设置数量，上限为核心数。

!**解码周期** +
image:menu-Decode-Parameters-Decoding_cycles.png[解码周期]
!**1**、**2** 或 **3**（默认）个周期，每个周期 3 遍，即共 3、6 或 9 遍。
周期越多，找到的弱信号越多，但耗时越长。早期解码（见
**开始解码**）始终使用 2 个周期。

!**通联接收频率灵敏度** +
image:menu-Decode-Parameters-QSO_RX_freq_sensitivity.png[通联接收频率灵敏度]
!**低**、**中等**（默认）、**高**。一个特殊解码器的阈值，
该解码器在 QSO 期间于你的接收频率上寻找 DX 呼号的预期信息。
越高解码越多，但错误解码也越多。
在猎犬模式下始终使用 **低**。

!**解码灵敏度** +
image:menu-Decode-Parameters-Decoder_sensitivity.png[解码灵敏度]
!**最少**：正常的同步阈值。**使用低阈值**：较低的同步
阈值，因此会尝试更多候选信号。**使用子通道**（默认）：低
阈值加上额外的弱信号子遍。灵敏度越高，CPU 负载也越高。

!**开始解码** +
image:menu-Decode-Parameters-Decoder_start.png[开始解码]
!在 15 秒周期内何时开始解码。
**阶段-2**：约 11.8 秒早期解码，14.1 秒最终解码。
**阶段-3**：约在 11.8、13.2 和 14.4 秒。
**早期**：13.8 秒解码一次。**正常**（默认）：14.1 秒。
**最新**：14.4 秒。分阶段设置能更早显示强信号。

!**宽带 DX 呼号搜索**
!开启（默认）：在整个通带内对 DX 呼号的信息进行 AP 搜索。
关闭：只在接收频率附近的窄窗口内搜索。

!**隐藏 FT8 重複信息**
!开启（默认）：如果多个线程在一个周期内两次解码出同一条信息，
只显示一次，并采用较强的信号报告。

!**跳过 a8 解码**
!关闭 "a8" 尝试：即在接收频率上，根据 **DX 呼号** 和 **DX 网格**
构造 DX 呼号的预期信息进行解码。
!===

|**平均值**
|JT4、JT65 和 Q65，需启用 VHF 功能。对连续多个周期取平均，以
解码单个周期内过弱的信号。两个解码区域变为 **单周期解码**
和 **平均解码**。

|**启用深度搜索**
|JT4 和 JT65，需启用 VHF 功能。常规解码失败时，将
信号与根据你的呼号、DX
呼号、DX 网格和 `CALL3.TXT` 构造的可能信息进行比较。

|**启用增强解码**
|两个同名菜单项中的第一个。仅限 FT8：先验（AP）解码，
利用你的呼号、DX 呼号和 QSO 状态来找到更弱的信息。
AP 解码标记为 `a1` ... `a8`。

|**启用增强解码**
|第二个菜单项。仅限启用 VHF 功能的 JT65：用于 JT65 的 AP 解码。


|**解码后自动清除平均值**
|在接收频率的 **容差** 范围内成功解码后，清除
平均值，使下一条信息从头开始。

|**接受 WS-MAP/EME65 点击事件**
|Q65 和 JT65，需启用 VHF 功能（默认开启）。在
WS-MAP 或 EME65 中点击电台会在 WS 中设置 DX 呼号、网格、频率和周期。
开启 **双击呼号条启用发射** 时，双击还会开始 QSO。它还会
接收 EME65 转发的解码。

|**独占 WS-MAP**
|接受点击事件时显示。如果多个 WS 实例监视
同一个 WS-MAP/EME65 源，只有持有独占权的实例响应
点击。如果持有实例 10 秒内未刷新，独占权会自动
释放。主窗口上的 **独占 WS-MAP** 按钮作用相同。

a|**WS-MAP/EME65 源**

image::menu-Decode-QMAP_source.png[WS-MAP/EME65 源子菜单]
a|WS 监听哪一个 WS-MAP 或 EME65 实例。

* **自动**（默认）和 **1**：默认实例（WS-MAP 设置中 Instance ID 为 1 或
未设置）。只有一个 WS-MAP 时使用此项。
* **2**、**3**、**4**：仅限具有该 Instance ID 的实例。

更改源会释放所有独占权。更改立即生效；
建议之后重启 WS。

|**禁用在瀑布上点击**
|JT65 和 Q65，需启用 VHF 功能。防止误点瀑布图而改变你的
接收/发射偏移。按住 kbd:[Alt] 仍可点击。

|**隐藏 AP 信息**
|仅限 FT8。从显示的解码中去掉 `a1` ... `a9` 和 `?` 标记。

|**减少错误解码**
|FT8，特殊操作模式下不适用。丢弃看起来不合理的弱解码，
例如在低信噪比下出现 `/P`、`/R`、`R`、哈希
呼号或竞赛交换信息的奇怪组合。这些行不会写入 `ALL.TXT`。
使用单线程解码器时，如果呼号不在 `ALLCALL7.TXT` 中且看起来不像有效呼号，
低于 -20 dB 的解码也会被隐藏。

|**全双工模式**
|发射时继续接收和解码，例如使用来自
第二台接收机或 WebSDR 的音频。适用于 FT8、FT4、Q65、MSK144 和其他模式。
|===

[[MENU_MODE]]
=== 模式

image::menu-Mode.png[模式菜单]

选择工作模式。发射时菜单被锁定。各模式的
详细信息请参阅 WSJT-X 用户指南。

[cols="2,5",options="header"]
|===
|菜单项 |典型用途

|**FST4**
|LF/MF 和 HF 长周期（15 秒至 30 分钟）弱信号 QSO。

|**FT2**
|周期为 3.75 秒（FT4 的一半）的极快 77 位模式。由 WSJT-X Improved 3.1 引入。

|**FT4**
|竞赛和快速 HF QSO，周期 7.5 秒。

|**FT8**
|HF/6 m 日常模式，周期 15 秒。也用于 DX 远征（狐狸/猎犬）和超级狐狸。

|**JT4**
|微波 EME 和有多普勒扩展的地面路径。

|**JT9**
|HF/LF 弱信号，周期 1 分钟。

|**JT65**
|VHF/UHF 上的 EME 和传统 HF JT65。

|**Q65**
|VHF 至微波的 EME、电离层散射和雨散射。子模式 A-E，
周期 15-300 秒。与 WS-MAP 配合使用。

|**MSK144**
|6 m 和 2 m 流星散射。

|**FST4W**
|用于 LF/MF 的类似 WSPR 的信标模式，周期 2-30 分钟。

|**WSPR**
|用于传播研究的信标发射。报告发送到 WSPRnet。

|**Echo**
|EME 回波测试：测量你自己从月球返回的回波。

|**频率校准**
|电台的频率校准。见 <<MENU_TOOLS>>。
|===

[[MENU_TOOLS]]
=== 工具

image::menu-Tools.png[工具菜单]

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**擦除参考频谱**
|清除正在测量的参考频谱。

|**测量参考频谱**
|启动 **监听** 并对接收到的音频频谱取平均。点击
**停止** 将其保存到 `refspec.dat`。在频谱瀑布图中勾选
**参考规格**，即可用此滤波器使音频平坦化。

|**测量相位响应**
|开启或关闭 MSK144 相位训练。WS 根据来自
DX 呼号的解码进行训练，并将相位均衡系数保存到
数据目录中的文件。数据足够后训练会自动结束。

|**均衡工具 ...**
|打开一个窗口，绘制测量的、建议的和当前的相位及
群时延，以及参考频谱。用它来加载（**相位 ...**）、
刷新或丢弃相位均衡数据。

|**执行频率校准周期**
|在频率校准模式下，于每个周期结束时将电台调谐到
menu:文件[设置 > 频率] 中的下一个频率校准频率，以便
依次测量多个已知频率的电台。

|**修正校准参数**
|对 `fmt.all` 中的测量值拟合斜率（ppm）和截距（Hz），
并显示结果。**Apply** 将其保存为你在
menu:文件[设置 > 频率] 中的校准值。之后可将 `fmt.all` 重命名为 `fmt.bak`。
|===
