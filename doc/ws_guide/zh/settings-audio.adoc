[[SETTINGS_AUDIO]]
=== 音频

image::settings-audio.png[设置 - 音频选项卡,align="center"]

==== 声效卡

[cols="2,5",options="header"]
|===
|设置 |功能

|**输入** / **输出**
|连接到电台的声卡（例如电台的 USB 音频编解码器），
设置为 48000 Hz、16 位。右侧的框选择声道：
通常为 **单声道**，特殊配置下可选 **左声道**、**右声道** 或 **双声道**。

|**刷新**
|重新加载设备列表，例如插入 USB 电台之后。

|**使用 TCI 音频 (需要重新启动)** / **Rx 0 dB**
|仅在使用 TCI 电台（例如 SDR）时显示。此时音频通过
TCI 连接传输而不是声卡，设备显示为 **TCI audio**。
**接收** 用于降低接收音频电平（0 至 -50 dB）。更改后请重启
WS。

|**按字母顺序排列**
|按字母顺序排列设备名称，并只列出能够
录制或播放 PCM 音频的设备。不勾选时使用系统顺序。

|**隐藏 ALSA 音效卡子设备 (仅 Linux)**
|隐藏通常无法使用的 `CARD=` 条目。仅在勾选
**按字母顺序排列** 时有效。
|===

IMPORTANT: 如果输出设备同时也是计算机的默认声音
设备，请关闭所有系统声音。否则它们会被发射出去。

==== 保存目录

[cols="2,5",options="header"]
|===
|设置 |功能

|**目录位置** / **选择**
|menu:保存[] 所写入的 `.wav` 文件的文件夹。默认为日志目录中的 `save`
文件夹。
|===

==== AzEl 目录

[cols="2,5",options="header"]
|===
|设置 |功能

|**位置** / **选择**
|`azel.dat` 的文件夹，该文件保存太阳和月亮的位置以及多普勒数据，供
天线跟踪程序使用。天文数据窗口打开时，
它每秒更新一次。

|**为 azel.dat 启用额外的行**
|为读取这些数值的跟踪程序增加一行 Dpol、MNR、Dgrd 和回波宽度
数据。
|===

==== 按波段记忆设置功率

[cols="2,5",options="header"]
|===
|设置 |功能

|**发射**
|记住每个波段的 **功率** 滑块位置，并在更换波段时恢复。

|**调谐**
|为 **调谐** 按波段单独保存 **功率** 设置。调谐结束后，
滑块恢复为你的发射功率。
|===
