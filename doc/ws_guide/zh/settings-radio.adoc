=== 电台

image::settings-radio.png[设置 - 电台选项卡,align="center"]

==== 无线电设备

[cols="2,5",options="header"]
|===
|设置 |功能

|**无线电设备**
|你的电台型号，或控制电台的控制程序（DX Lab Suite
Commander、Flrig、Ham Radio Deluxe、Hamlib NET rigctl、OmniRig Rig 1/2、
TCI Client）。**无** 表示不使用 CAT 控制。

|**轮询间隔**
|WS 从电台读取频率和模式的频率。1–3 秒适合大多数
电台。对于能自行报告变化的电台，此项为灰色不可用。
|===

==== CAT 控制

[cols="2,5",options="header"]
|===
|设置 |功能

|**端口**
|CAT 接口的串口（例如 COM3 或 /dev/ttyUSB0）。对于
控制程序，此项变为 **网络服务器** 或 **TCI 服务器**
（`host:port`）；留空则使用本机的默认值。对于
少数 SDR 套件，此项变为 **USB 设备**。

|**波特率** / **数据位元** / **停止位元**
|必须与电台的 CAT 菜单一致。**默认值** 保留 Hamlib
为你的型号所设的值。

|**握手方式**
|通常为 **无**。少数电台，尤其是某些 Kenwood，需要
**硬件**（RTS/CTS）。设置错误会导致 CAT 无响应。

|**强制控制线** **DTR:** / **RTS:**
|将 DTR 或 RTS 固定保持为 **高** 或 **低**，例如为
接口供电。除非确知需要，否则请留空。如果某条线
已在同一端口上用于 PTT，则该线不可用。
|===

==== 更新 Hamlib

这些选项来自 WSJT-X Improved，WSJT-X 中没有。它们只能
在 Windows 上使用；在 Linux 和 macOS 上，该框名为 **Hamlib Version**，
仅显示正在使用的版本。

[cols="2,5",options="header"]
|===
|设置 |功能

|**64-位元** / **32-位元**
|要下载哪种 Hamlib DLL。请选择与你的 WS 安装相符的版本。

|**更新 Hamlib**
|下载最新的 Hamlib DLL，它常常会新增或修复对电台的支持。
当前 DLL 会保留为备份。重启 WS 后使用新的 DLL。

|**恢复更新**
|恢复到备份的 DLL，同样需要重启后生效。

|**使用中** / **已备份**
|WS 正在运行的 Hamlib 版本以及备份的版本。
|===

==== PTT 方法

[cols="2,5",options="header"]
|===
|设置 |功能

|**VOX**
|由电台的 VOX 控制发射机。无需接口。

|**CAT**
|通过 CAT 命令控制 PTT（如果电台支持）。使用
OmniRig 或 Flrig 等控制程序时通常是正确选择。

|**DTR** / **RTS**
|由串口控制线控制电台发射。许多 USB 电台可以将该线映射为
PTT（Icom：USB SEND，Yaesu：PC KEYING）。在使用 **硬件** 握手的
CAT 端口上，**RTS** 不可用。

|**端口**
|**DTR** / **RTS** 使用的串口；可以与 CAT 端口相同。值
**CAT** 用于 OmniRig 等远程切换控制线的接口。

|**启用 TX 禁止**
|用于与优先电台共用波段的电台（仅限 **DTR** / **RTS** PTT）：
当该电台发射时，其他程序可以阻止 WS 发射。
|===

==== 无线电设备音频源

[cols="2,5",options="header"]
|===
|设置 |功能

|**后方/数据口** / **前方/麦克风**
|通过 CAT 选择电台的发射音频输入（如果电台支持）。
仅在 PTT 方法为 **CAT** 时有效。**后方/数据口** 通常最佳。
|===

==== 模式

[cols="2,5",options="header"]
|===
|设置 |功能

|**无** / **上边带** / **数据/封包**
|WS 在电台上设置的模式。如果电台有 **数据/封包** 就选它（通常
会选择后面板音频输入和较宽的滤波器），否则选 **上边带**。
**无** 表示不改变模式。
|===

==== 异频操作

[cols="2,5",options="header"]
|===
|设置 |功能

|**无线电设备**
|使用电台自身的异频功能（VFO A 和 B）。

|**软件虚拟**
|只使用 VFO A，每次发射时重新调谐。适用于任何电台。

|**无**
|不使用异频（不推荐）。
|===

使用异频时，WS 以 500 Hz 步进移动发射显示频率，使发射音频
保持在 1500 到 2000 Hz 之间。这样音频谐波就落在
电台滤波器之外，你的信号保持干净。这适用于 FT4、FT8 和
FST4，以及关闭 **启用甚高频和子模式功能** 时的所有模式。
多普勒跟踪也需要异频。

==== 测试 CAT 和测试 PTT

[cols="2,5",options="header"]
|===
|设置 |功能

|**测试 CAT**
|用这些设置连接电台。绿色：正常。红色：出错，并显示
信息。

|**测试 PTT**
|在无音频的情况下使发射机发射；再次点击即释放。检查
电台和接口是否按预期切换。使用 **VOX** 时请改用
主窗口上的 **调谐**。
|===

==== 无线电设备数据

这些选项来自 WSJT-X Improved，WSJT-X 中没有。

[cols="2,5",options="header"]
|===
|设置 |功能

|**显示 PWR, SWR 和 ALC**
|发射时显示输出功率（以瓦为单位，位于 **功率**
滑块旁），并在状态栏中显示 SWR 和 ALC。SWR 高于 1.5 时该字段变为
黄色，高于 2.0 时变为红色。需要能报告这些数值的电台；使用
**无**、OmniRig、DX Lab Suite Commander、Ham Radio Deluxe
或 Kenwood TS-480/850/870 时不可用。

|**当驻波比大于 2.5 时停止发射**
|立即停止发射并显示警告。请检查天线。

|**突出显示 ALC > 50%** / **突出显示 ALC > 90%**
|ALC 超过限值时，状态字段变为黄色 / 红色，让你
察觉过激励。
|===

最后三个选项需要开启 **显示 PWR, SWR 和 ALC**。
