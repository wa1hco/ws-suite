==== 频率校准

[cols="2,5",options="header"]
|===
|设置 |功能

|**倾斜率** / **拦截**
|校正电台已知的显示频率误差： +
`rig frequency = Intercept + (1 + Slope / 1 000 000) × f` +
其中 **拦截**（Intercept）单位为 Hz，**倾斜率**（Slope）单位为 ppm。发送给电台和
从电台读回的频率都会被校正，因此 WS 显示的是真实频率。如果电台准确，
两者都保持为 0。
|===

TIP: 如何测量这些数值，请参阅 WSJT-X 用户指南中的 __Frequency Calibration__
（频率校准）一节（FreqCal 模式）。

==== 工作频率

主窗口波段选择框中提供的频率。WS 只显示
适用于你的 **IARU 分区**（**常规** 选项卡）和当前模式的条目。
双击单元格即可编辑。

[cols="2,5",options="header"]
|===
|列 |功能

|**IARU 分区** / **模式**
|条目在何处、针对何种模式提供。值为 **全部** 的条目
在所有地区 / 所有模式中提供。

|**频率**
|以 MHz 为单位的显示频率。

|**优先**
|该波段和模式的首选条目。点击波段按钮
（menu:显示[]）或 WS 自行更换波段（波段跳换）时使用它。每个波段和模式
只能有一个首选条目。

|**描述**
|你为该条目定义的标签，显示在波段选择框中。

|**开始日期/时间** / **结束日期/时间**
|条目只在此时间段内提供，例如用于 DX 远征。留空 = 始终提供。
|===

右键点击表格可执行以下操作：

[cols="2,5",options="header"]
|===
|菜单项 |功能

|**删除**
|删除所选条目。

|**插入 ...**
|添加条目：**IARU 分区**、**模式**、**频率 (兆赫)**、**首选波段/模式**、
**描述** 以及可选的日期范围。

|**加载 ...**
|用 `.qrg` 或 `.qrg.json` 文件中的列表替换当前列表（WS 会先询问）。

|**另存为 ...**
|将列表保存到文件；文件名以 `.qrg.json` 结尾时保存为 JSON 文件。
如果选中了条目，WS 会询问是否只保存所选条目。

|**合并 ...**
|将 `.qrg` 或 `.qrg.json` 文件中的条目添加到列表中。

|**重置**
|恢复默认列表（WS 会先询问）。
|===

==== 电台信息

电台的各波段详细信息。双击单元格即可编辑。

[cols="2,5",options="header"]
|===
|列 |功能

|**波段**
|该行适用的波段。

|**偏移**
|加到显示频率上得到电台频率，用于
收发转换器。例如：144 MHz 使用 28 MHz 中频时需要 -116 MHz。默认为 0。

|**天线描述**
|在此波段上时发送给 PSK Reporter。
|===

右键点击表格可选择 **删除**（删除所选行）和
**插入 ...**（添加一行：**波段**、**偏移 (MHz)**、**天线**）。

TIP: 要快速创建行，可在 **工作频率** 中选择条目（kbd:[Ctrl]+kbd:[A]
全选），然后拖到 **电台信息** 上。再填写偏移和
天线。
