== 三种界面版本

WS 始终提供**三种界面版本**。它们的功能、
菜单和设置完全相同，只是主窗口的布局不同。
每个版本都有自己的安装程序。

[cols="1,3",options="header"]
|===
|版本 |适用场景

|**WS**（标准版）
|熟悉的 WSJT-X 布局。这是默认下载版本。

|**WS AL**（替代布局）
|窗口更紧凑，波段活动区域更大，减少滚动。

|**WS Widescreen**
|宽屏显示器：控件移到侧边，解码区域占满整个高度。
|===

TIP: 可以将各版本并排安装在不同的文件夹中进行
比较。它们都使用同一个设置文件（`WS.ini`），因此你的
配置可以沿用。WS 首次启动时会接管已有 WSJT-X 安装的
设置。

要同时运行多个实例，请为每个实例使用各自的
`--rig-name=NAME` 启动；每个实例都会保留自己的设置文件。
