[[SETTINGS_ALERTS]]
=== 警报

image::settings-alerts.png[设置 - 警报选项卡,align="center"]

WS 可以用简短的语音警报播报所选的解码（"New DXCC"、
"My Call" 等）。警报包含在每个 WS 安装中，并且
始终在计算机的默认音频设备（通常是扬声器）上
播放。

WARNING: 音频警报需要第二个声音设备。你的电台**不得**
通过默认音频设备连接，否则警报会被发射出去。
内置 USB 声卡的电台（IC-7300、FT-991 等）满足
这一要求。启用前请先测试（见下文 **测试**）。

==== 音频警报

[cols="2,5",options="header"]
|===
|设置 |功能

|**语音**
|选择警报使用的语音。标准安装只有一个语音 **默认**。

|**测试**
|在默认音频设备上播放测试播报，以便检查
警报从哪里输出。

|**新 DXCC** / **新 DXCC 波段**
|尚未通联过 / 在当前波段上尚未通联过的 DXCC 实体。

|**新大洲** / **新大洲 波段**
|尚未通联过 / 在本波段上尚未通联过的大洲。

|**新 CQ 分区** / **新 CQ 分区 波段**
|尚未通联过 / 在本波段上尚未通联过的 CQ 分区。

|**新 ITU 分区** / **新 ITU 分区 波段**
|尚未通联过 / 在本波段上尚未通联过的 ITU 分区。

|**新美国州** / **新美国州 波段**
|尚未通联过 / 在本波段上尚未通联过的美国 50 个州之一。
州由呼号确定；如果网格只对应一个州，也可由网格确定。

|**新网格** / **新网格 波段**
|尚未通联过 / 在本波段上尚未通联过的网格定位符。只计算带网格的信息。

|**我的呼号**
|发给你的信息。

|**DX 呼号或 DX 网格在信息内**
|**DX 呼号** 框中的呼号或 **DX 网格** 框中的网格出现在解码中。

|**CQ 信息**
|任何 CQ 呼叫。

|**渴望的呼号, 网格, 前缀和定向呼叫**
|解码与你在 **颜色** 选项卡上的 **突出显示橙色** 或 **突出显示蓝色** 条目匹配
（仅在该突出显示开启时），或在勾选
menu:过滤[突出显示白名单条目] 时与白名单条目匹配。

|**信息已接收**
|收到发给你的呼号或 DX 呼号的 QSY 信息。只有 QSY 信息
会触发此警报，因此很少出现。

|**启用音频警报**
|总开关：关闭时不播放任何警报声音。开启时按钮
变为绿色。在 Windows 上，WS 还会在启动时播放一段简短的测试声音。
|===

分隔线以上的类别需要在 **常规** 选项卡上勾选 **显示 DXCC, 网格和曾经通联状态**。

警报与 **颜色** 选项卡上的突出显示相互独立。但只有
在那里开启了相应的突出显示，你才能看出是哪条解码触发了警报，
因此请在两个选项卡上启用相同的类别。

NOTE: 忽略列表中的电台（通过 **DX 网格** 下方的 **忽略** 按钮
添加）除 **我的呼号** 外不会触发警报，除非勾选了 **绕过**
复选框。使用 menu:文件[删除忽略列表] 清空列表。

TIP: 波段跳换关闭时，右键点击主窗口上的 **监听波段跳换** 按钮，
可对默认音频设备进行较长时间的测试。
