==== JT65 VHF/UHF/Microwave 解码参数

[cols="2,5",options="header"]
|===
|设置 |功能

|**随机擦除模式**
|JT65 软判决解码器的尝试力度（最多 10^n/2^ 个模式）。
数值越高灵敏度略高，但速度更慢；6 或 7 适合大多数电台。

|**主动解码级别**
|JT65 深度搜索的阈值（0–10）。级别越高解码越多，
但错误解码也越多。

|**通过二次解码**
|JT65：减去第一遍找到的信号后，再进行
第二遍解码。
|===

==== 针对高分辨率显示器的用户介面调整

[cols="2,5",options="header"]
|===
|设置 |功能

|**高 DPI 缩放 (需要重启)**
|跟随操作系统的显示缩放，使控件在 4K 显示器上更大且
比例合适。默认开启。

|**增加了选项卡小部件的高度 (需要重新启动)**
|允许主窗口中的发射信息选项卡变得更高。
|===

==== 杂项

[cols="2,5",options="header"]
|===
|设置 |功能

|**降低信噪比的 .wav文件** / **接收带宽**
|用于离线灵敏度测试：向你打开的 .wav 文件中加入噪声，使
信噪比降低指定的 dB 数。将 **接收带宽** 设为接收机的噪声
带宽，数值才准确。

|**发射延迟**
|从 PTT 到开始发射音频的最短时间（0 至 0.5 秒）。FT4 和
FT2 始终使用 20 ms。

|**音调间距**：**x 2** / **x 4**
|两倍 / 四倍于正常的音调间距，用于将频率除以 2 或 4 的
LF/MF 发射机。两者只能勾选其一。

|**瀑布频谱**：**低侧边** / **最敏感**
|**低侧边**（默认）使用加窗 FFT，使强信号在瀑布图上
扩散较少。**最敏感** 不使用窗函数，显示极
弱的信号轨迹略好一些。
|===

IMPORTANT: **发射延迟** 不能替代硬件时序控制器。为保护
收发继电器和前置放大器，请使用时序控制器并测试时序是否正确。

==== 特殊操作活动

勾选该框并选择一项活动；WS 随后会生成相应的
信息格式。

[cols="2,5",options="header"]
|===
|设置 |功能

|**NA VHF**
|北美 VHF/UHF/微波竞赛以及其他以 4 字符
网格作为交换信息的竞赛。

|**NCCC Sprint**
|仅与 **NA VHF** 配合：用于 FT4（和 FT2）的 NCCC Sprint 短信息协议。

|**EU VHF Contest**
|欧洲 VHF 及以上竞赛：信号报告、流水号和 6 字符定位符。

|**WW Digi Contest** / **ARRL Digi Contest**
|World-Wide Digi 竞赛 / ARRL International Digital Contest。

|**Q65 堆叠**
|交换 4 字符定位符而不是信号报告，使 DX 操作员获得
q3 级灵敏度。尤其适用于 6 m EME DX 远征。

|**ARRL Field Day** / **FD 交换**
|你的交换信息：发射机数量、类别和 ARRL/RAC 分区，或 "DX"
（例如 `6A SNJ`）。

|**FT Roundup messages** / **FT RU 交换**
|FT Roundup 及类似竞赛。交换信息：美国州、加拿大省或
"DX"（阿拉斯加和夏威夷也用 "DX"）。

|**狐狸** / **猎犬**
|FT8 DX 远征模式：**狐狸** 用于 DX 远征队，**猎犬** 用于呼叫它。使用前请阅读
FT8 DX 远征模式用户指南。

|**超级狐狸模式**
|配合 **狐狸** 或 **猎犬**：发射或接收超级狐狸波形。

|**OTP** / **密钥** / **间隔**
|配合 **狐狸** 或 **猎犬**：对狐狸进行一次性密码验证（需要
互联网）。狐狸输入其 16 字符的 **密钥**，并每隔 **间隔** 条
信息签名一次（1 = 每条信息）。

|**显示 OTP 信息** / **OTP 网址**
|用于猎犬：WS 在 **OTP 网址**（默认
`https://www.9dx.cc`）核验狐狸的代码。**显示 OTP 信息** 在波段活动中显示验证
信息。

|**CQ 单独竞赛名称** / **竞赛名称**
|呼叫例如 `CQ PACC`，而不是 CQ TEST、RU 或 WW。在
**狐狸**、**猎犬** 或 **Q65 堆叠** 下不可用。
|===

==== 上传通联到 Cloudlog 或 Wavelog

[cols="2,5",options="header"]
|===
|设置 |功能

|**上传通联到 Cloudlog 或 Wavelog**
|勾选该组标题，即可将每个已记录的 QSO 发送到你的 Cloudlog 或
Wavelog 服务器。

|**API 网址**
|你的安装的基本地址，末尾不加斜杠
（例如 `https://log.example.com`）。

|**API 密匙** / **电台 ID**
|具有写权限的 API 密钥，以及 Cloudlog/Wavelog 中的电台配置 ID。

|**测试 API 密匙**
|以试运行（dry-run）方式发送一个测试 QSO。密钥
可写时按钮变为绿色，只读时变为橙色，无效时变为红色。
|===

==== 上传通联到 eQSL.cc

[cols="2,5",options="header"]
|===
|设置 |功能

|**上传通联到 eQSL.cc**
|勾选该组标题，即可将每个已记录的 QSO 上传到 eQSL.cc。

|**用户名** / **密码**
|你的 eQSL.cc 登录信息。

|**QTH**
|你的 QTH 昵称（如果你在 eQSL.cc 上有多个 QTH）。
|===

NOTE: eQSL.cc 密码和 API 密钥以未加密形式保存在
设置文件中。
