[[SETTINGS_GENERAL]]
=== 常规

image::settings-general.png[设置 - 常规选项卡,align="center"]

==== 电台详情

[cols="2,5",options="header"]
|===
|设置 |功能

|**我的呼号**
|你的呼号。

|**我的网格**
|你的梅登海德网格定位符，最好为 6 个字符（例如 CM87ux）。
距离和方位角都据此计算。

|**自动网格**
|允许外部程序（例如 GPS 辅助程序）更改 **我的网格**。

|**IARU 分区**
|分区 1：欧洲、非洲、中东、亚洲北部。分区 2：
美洲。分区 3：亚洲南部和太平洋地区。选择相应的
默认频率。

|**生成第2类复合呼号持有者的信息**
|仅适用于带有不在
简短列表（menu:帮助[类型 1 前缀和后缀列表]）中的附加前缀或后缀的呼号。选择
由哪条生成的信息（Tx1、Tx3 或 Tx6）携带你的完整呼号。
|===

==== 显示

[cols="2,5",options="header"]
|===
|设置 |功能

|**解码新讯息从顶部往下滚动**
|每个周期从波段活动顶部开始显示且不会滚动
消失，因此在解码仍在进行时即可双击。

|**每个解码周期插入间隔行**
|在波段活动中的周期之间插入分隔行。

|**显示带有时间戳的空行**
|分隔行同时显示该周期的 UTC 时间。

|**显示距离单位为英里**
|以英里代替公里。

|**突出显示 DX 呼号** / **突出显示 DX 网格**
|在信息中标记当前 QSO 对方的呼号和网格。

|**发出讯息在接收窗口显示**
|你自己发射的信息也显示在接收信息区域中。

|**在发给我们的信息中突出显示 RRR/RR73/73**
|让 QSO 的结束一目了然。

|**显示 DXCC, 网格和曾经通联状态**
|在解码中加入国家/地区以及新 DXCC / 新网格 / 曾经通联标记。
**颜色** 选项卡上的突出显示需要此项。

|**显示前缀而不是国家或地区名称**
|更简短：显示 "DL" 而不是 "Fed. Rep. of Germany"。

|**所有信息皆显示 DXCC**
|为每条信息加上国家/地区，而不仅限于 CQ 呼叫。

|**软件字体...** / **解码字体...**
|整个程序的字体 / 波段活动和接收信息区域的字体。
|===

==== 惯常方式

[cols="2,5",options="header"]
|===
|设置 |功能

|**开启时关闭监听**
|WS 启动后不解码，直到你点击 **监听**。

|**开始监听时使用上一次的频率**
|开启 **监听** 时返回上次监听的频率。
不勾选时保持电台当前频率。

|**双击呼号条启用发射**
|双击解码后立即开始发射。

|**发送 73 后关闭发射**
|发送 73 或自由文本信息后关闭 **启用发射**。

|**CQ 呼叫时强制呼叫第 1**
|你呼叫 CQ 时会勾选 **Call 1st**，使 WS 自动应答第一个呼叫者。

|**绑定 F1-F6 功能**
|将发射信息的 kbd:[F1]–kbd:[F6] 快捷键切换为竞赛
分配方式（见 menu:帮助[键盘快捷键表]）。

|**启用甚高频和子模式功能**
|显示 VHF/UHF/微波控件（子模式、平均、短信息、自动 QSY
等）。在 HF 上请关闭：它会禁用宽带 JT65 多重解码。

|**允许发射期间改变频率**
|如果电台在发射期间无法处理 CAT 命令，请取消勾选（使用异频时常常需要）。

|**EME 延迟后解码**
|在 1 分钟模式中推迟开始解码，以便包含延迟约 2.5 秒的
EME 信号。

|**单独解码**
|用于 JT4、JT65、Q65 和 FST4：只在接收频率附近
（**容差** 范围内）解码，而不搜索整个通带。在 JT4/JT65/Q65 中，
两个区域变为 **单周期解码** 和 **平均解码**。

|**调谐计时器**
|在设定的秒数后停止 **调谐**。

|**MSK144/Q65: 发射直到接收到 73**
|持续发送直到收到对方的 73，最多尝试 10
次。有助于完成困难的 VHF/UHF/SHF QSO。

|**自动打开/关闭 天文数据窗口**
|在开启 **EME 延迟后解码** 的情况下切换到 Q65 或 JT65 时打开天文数据窗口，
不再需要时将其关闭。

|**kHz 输入没有 'k' (需要重启)**
|在频率框中输入 "164" 后按 kbd:[Enter]，表示当前 MHz 内的
+164 kHz（438.065 -> 438.164 MHz）。便于用数字小键盘在 EME
频段之间跳转。

|**发射时将进度条变为红色**
|一眼就能看出正在发射。

|**73 发送后使用 CW 发送您的呼号** / **时间间隔**
|在每次 73 或自由文本后 / 每 N 分钟（0 = 关闭）发送一次 CW 呼号，
总是在周期的静默部分发送。

|**发射计时器**
|在设定的分钟数后停止无人值守的发射。
|===

==== 附加功能

这些选项来自 WSJT-X Improved，WSJT-X 中没有。

[cols="2,5",options="header"]
|===
|设置 |功能

|**显示美国州**
|将网格定位符对应到美国州和加拿大省（在不使用
JTAlert 时很有用）。有些网格跨越多个州，此时会全部列出。

|**启用等待功能**
|开启 **等待和回复**、**等待和呼叫** 和 **等待和突袭**（默认）。
见 <<WAIT_FEATURES>>。

|**通联后清除DX呼号** / **通联后清除 DX 网格**
|QSO 记录后清空 DX 呼号 / DX 网格框。

|**在信息中带网格的显示距离** / **在信息中带网格的显示方位角**
|为每条含有效定位符的信息加上距离和大圆方位角。

|**波段改变后擦除解码** / **模式改变后擦除解码**
|更换波段 / 模式时清除波段活动。

|**备用擦除按钮行为**
|**擦除** 的工作方式与 JTDX 相同：左键点击清除波段活动，
右键点击清除接收信息，双击同时清除两者。

|**通联后将接收频率设置为发射频率**
|记录日志后，接收频率移到你的发射频率。

|**每分钟切换波段**
|开启波段跳换时，WS 通常每隔一分钟更换一次波段。
勾选此项则每分钟更换波段。

|**对齐 DXCC, 距离和方位** 及两个数字框
|将国家/地区、距离和方位角按列对齐。第一个框设置
信息与国家/地区之间的空格数（不勾选 **对齐 DXCC, 距离和方位** 时也有效），
第二个框设置国家/地区与距离/方位角之间的空格数。
|===

NOTE: 如果你使用带附加前缀或后缀的呼号，或想与
这样的电台通联，请阅读 WSJT-X 用户指南中的 __Nonstandard Callsigns__（非标准呼号）一节。
