== WS 用户指南

[preface]
== 关于本指南

WS 是一套用于业余无线电弱信号数字通信的程序：**WS**（主程序）、**WS-MAP**（宽带 Q65/FT8
监听程序）和 **EME65**（用于 EME 的宽带 JT65/Q65）。WS 源自
__WSJT-X__，曾用名 __WSJT-X Improved__。所有模式和基本操作
流程都与 WSJT-X 相同；这些内容仍以
https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-3.0.0-rc1.html[WSJT-X 用户指南]
为准。

本指南刻意保持简短。它说明 WS 的每个菜单和每项
设置，以及 WS 在 WSJT-X 基础上增加的功能。
