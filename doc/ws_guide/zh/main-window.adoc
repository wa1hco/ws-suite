[[MAIN_WINDOW]]
== 主窗口

WS 主窗口的外观和操作与 WSJT-X 主窗口相同，但增加了
一些按钮和更多鼠标操作。标准控件请参阅 WSJT-X 用户指南。
本章只介绍 WS 中新增或不同的内容：即菜单和 **设置** 对话框
之外你所操作的一切。
menu:帮助[特殊鼠标命令表] 提供了简要汇总。

[[WAIT_FEATURES]]
=== 等待功能

当对方电台没有立即应答，或因 QSB 信号衰落时，等待功能可以替你
完成 QSO。它们都需要勾选 **自动完成**，并在 **常规** 选项卡上开启
**启用等待功能**（默认开启，见
<<SETTINGS_GENERAL>>）。

WARNING: 等待功能处于待命状态时，收到的信息可能会在你不做任何操作的情况下
使电台切换到发射。请让功放、天调和天线保持就绪，
或者解除该功能。

[cols="2,5",options="header"]
|===
|功能 |工作方式

|**等待和回复**（Wait and Reply）
|当 **DX 呼号** 中有呼号且 **启用发射** 处于关闭状态时自动待命。
当该电台呼叫你（信息中含有你的呼号和他的呼号，
且不含 73）时，WS 会开启 **启用发射** 并继续 QSO。如果对方
没有抄收到第一次的 RR73，它还会再次发送 RR73。适用于
FT2、FT4、FT8、FST4、JT4、JT9、JT65、MSK144 和 Q65。8 个周期后
（MSK144 为 12 个）发射会再次关闭。

|**等待和呼叫**（Wait and Call）
|点击 **DX 呼号** 按钮（变为红色）。当 **DX 呼号** 中的电台
再次出现 CQ、RRR、RR73 或 73 时，WS 最多呼叫他三次。
适用于 FT2、FT4、FT8、FST4、MSK144 和 Q65，可在普通操作中使用，也可作为
FT8 猎犬使用。以下操作会解除该功能：**终止发射**、**停止**、关闭 **启用发射**、
再次点击 **DX 呼号**，或者该电台应答你时（QSO
随后正常继续）。

|**等待和突袭**（Wait and Pounce）
|选择 **CQ: None** 以外的 **CQ:** 模式（见 <<CQ_SELECTOR>>），然后
右键点击 **启用发射**（变为橙色）。WS 会应答下一个 CQ：本周期内
第一个、距离最远、信号最强或最弱的电台。再次右键点击 **启用发射**，
或点击 **终止发射** 或 **停止** 即可解除。作为狐狸时不可用。
|===

等待和突袭会遵循过滤设置。例如，WS 可以只等待带有特定前缀、网格、
呼号或关键字的 CQ。勾选
**為 等待和突袭, CQ:第一, 等使用过滤. 仅 (仍显示所有信息)** 后，所有解码仍然可见，但等待和突袭
只应答通过过滤的电台（见 <<SETTINGS_FILTERS>>）。

只要收到的信息可能开启发射，**启用发射** 和 **DX 呼号** 就会变为黄色：
即 **DX 呼号** 中有呼号、**自动完成** 开启且等待
功能已启用时，以及在猎犬模式下始终如此。右键点击 **DX 呼号** 可
清除 **DX 呼号**、**DX 网格** 和标准信息；这会同时解除等待和回复
以及等待和呼叫。

[[CQ_SELECTOR]]
=== CQ: 选择框和忽略列表

勾选 **自动完成** 后，其旁边的 **CQ:** 选择框才会显示。

[cols="2,5",options="header"]
|===
|选项 |效果

|**CQ: None**
|WSJT-X 的标准行为。

|**CQ: First**
|你呼叫 CQ 时，WS 应答第一个呼叫你的电台。配合等待
和突袭时，它应答第一个 CQ。

|**CQ: Max Dist**
|选择距离最远的电台（计算距离需要网格）。

|**CQ: Max dB** / **CQ: Min dB**
|选择信号最强 / 最弱的电台。
|===

**忽略** 按钮（或 kbd:[Ctrl+I]）会把 **DX 呼号** 中的呼号加入
忽略列表。勾选 menu:过滤[从忽略列表中忽略呼号] 后，
**CQ:** 模式（等待和突袭）会跳过这些电台；
menu:过滤[从忽略列表中隐藏呼号] 会将它们从波段活动中
移除。使用 menu:文件[删除忽略列表] 清空列表。其他 **忽略** 和 **隐藏** 选项见
<<MENU_FILTERS>>。

[[MOUSE_SHORTCUTS]]
=== 鼠标和按钮快捷操作

==== 频谱瀑布图

[cols="2,5",options="header"]
|===
|操作 |效果

|左键点击
|设置接收频率。

|右键点击 / kbd:[Shift]+左键点击
|设置发射频率。

|右键双击 / kbd:[Ctrl]+左键点击
|将接收和发射设为同一频率（Rx = Tx）。

|**游标条** 复选框
|在瀑布图上显示接收（绿色）和发射（红色）频率标记条。

|**频率** 复选框
|提示框显示鼠标指针所在位置的音频频率。

|**时间戳**
|在瀑布图的 **左边** 或 **右边** 显示 UTC 时间，或选择 **取消**。
|===

==== 瀑布图上的呼号

使用 menu:显示[瀑布上的呼号 > 显示已解码呼号]（或频谱瀑布图中的 **显示呼号**）后，
已解码的呼号会作为标签显示在瀑布图上对应的频率处：**DX 呼号** 中的呼号为红色，
CQ 为绿色，其余为黑色。**× TR** 框设置标签
保留的周期数；**清除** 移除所有标签。左键点击标签可将呼号和
网格填入 **DX 呼号** / **DX 网格**，将接收频率设到该信号，为应答设置 **发射偶数/第一**，
并生成标准信息。字体、透明度和
位置在 **显示** 菜单中（见 <<MENU_VIEW>>）。在 Q65 中，
menu:解码[禁用在瀑布上点击] 可关闭标签点击。

==== 按钮

[cols="2,5",options="header"]
|===
|操作 |效果

|右键点击 **调谐**
|通过 CAT 启动电台的天调。按钮显示 **Tuning** 6 秒；
再次右键点击可停止。需要支持调谐的 Hamlib 电台型号。

|右键点击 **启用发射**
|待命或解除等待和突袭（<<WAIT_FEATURES>>）。

|点击 **DX 呼号** / 右键点击 **DX 呼号**
|待命等待和呼叫 / 清除 **DX 呼号**、**DX 网格** 和信息。

|右键点击 **查找** / **添加** / **忽略**
|在浏览器中于 qrz.com / hamqth.com / qrzcq.com 查询 **DX 呼号** 中的呼号。

|**擦除**
|启用 **备用擦除按钮行为**（<<SETTINGS_GENERAL>>）时：点击
清除波段活动，右键点击清除接收信息，双击同时清除
两者。

|右键点击 **解码**
|清除卡住的解码器。

|右键点击 **仅显示CQ**
|只显示含有 **DX 呼号** 中呼号的信息。该框变为红色
并显示 **DX 呼号**；再次右键点击即可恢复。

|右键点击 **Tx5**
|保留你的 Tx5 自由文本（黄色），使其不被清除。

|右键点击 **发射偶数/第一**
|冻结该复选框。右键点击 **MSK** 按钮可解除冻结。
// CHECK: Uwe will test whether the FT8 button also unfreezes (Help text and tooltip say so; the code only does it for MSK).

|右键点击 **猎犬**
|开启或关闭超级狐狸模式。

|右键点击 **FT8**
|开启或关闭上次使用的特殊操作活动。

|右键点击 **Q65** / **JT65**
|切换到 Q65 堆叠模式 / JT9。

|在显示频率上滚动鼠标滚轮，或左键点击 / 右键点击
|将显示频率改变 -1 kHz / +1 kHz。
|===

[[BAND_BUTTONS]]
=== 波段按钮

menu:显示[波段按钮] 会增加一排波段按钮，三种界面版本
均可使用。点击按钮即可转到频率列表中当前模式在该波段的
频率。在 FT8、FT4 和 FT2 中，右键点击 80 m 至 10 m 可转到
该波段的 FT8 DX 远征频率（6 m：仅 FT8）。
menu:显示[VHF / UHF 按钮] 将按钮切换为 8 m 至
13 cm 的波段。

在 2 m 上，右键点击转到 4 m（分区 1 和分区 3）或 1.25 m（分区 2）；
在 70 cm 上，右键点击转到 23 cm。

[[MAIN_FILTERS]]
=== 主窗口中的过滤

当过滤隐藏了解码时，左下角的状态标签会有所显示：它
从绿色的 **接收** 变为青色的 **Receiving, Filters On**。勾选 **绕过**
可暂时关闭所有过滤，而不会丢失其
设置；此时标签显示 **Receiving, Filters bypassed**。过滤
列表在 **过滤** 选项卡上设置（<<SETTINGS_FILTERS>>）；快速
过滤在 **过滤** 菜单中（<<MENU_FILTERS>>）。

[[BAND_ACTIVITY_INFO]]
=== 距离、方位角和美国州

如果信息中含有有效的网格定位符，波段活动可以显示
距离和大圆方位角，并与国家/地区对齐成列。
开启 **显示美国州** 后，还会显示美国州或加拿大省。
在 **常规** 选项卡上开启这些功能并设置列间距
（<<SETTINGS_GENERAL>>）。

[[CONTEST_NAME]]
=== 竞赛名称和注释

在 **进阶设置** 选项卡上开启 **CQ 单独竞赛名称** 并填写最多 4 个字母的 **竞赛名称**（例如 PACC）后，
当特殊操作活动处于启用状态时（FT 模式、MSK144、
Q65；狐狸或猎犬除外），WS 会呼叫 "CQ PACC"，而不是 "CQ TEST" 或
"CQ RU"。

在 **报告** 选项卡上开启 **特殊操作活动注释**
（<<SETTINGS_REPORTING>>）后，**记录通联** 的注释会填入
该活动，例如 "EU VHF Contest"、"ARRL Field Day"，或在使用单独
竞赛名称时填入 "PACC Contest"。保留的注释和 **把 dB 信号报告写入注释栏**
优先。

[[LIVECQ_CHECKS]]
=== LiveCQ：谁听到了我

在 **报告** 选项卡上开启 **启用 Q65 LiveCQ**（<<SETTINGS_REPORTING>>）
并使用 Q65 模式时，WS 每个周期向 LiveCQ 服务器查询一次哪些电台
解码到了你的呼号。这些电台的瀑布图标签上会出现勾号和亮
绿色边框，在 Q65 堆叠模式下活动电台窗口中也会出现勾号。
这样 DX 就能挑选真正抄收到他的呼叫者。活动
电台窗口底部显示 **LiveCQ connected** 或红色的 **LiveCQ NO CONNECTION**。

[[TX_INHIBIT]]
=== TX 禁止

在 **电台** 选项卡上开启 **启用 TX 禁止**（<<SETTINGS_RADIO>>）后，当同一波段上
的优先电台发射时，其他程序可以阻止 WS 发射。
此时状态标签显示 **禁止**。

[[WSMAP_CLICKS]]
=== 从 WS-MAP 和 EME65 点击通联

勾选 menu:解码[接受 WS-MAP/EME65 点击事件] 后，在 WS-MAP 或 EME65 中
点击呼号会在 WS 中设置 **DX 呼号**、**DX 网格**、频率、
发射周期和子模式。在那里双击还可以开启
**启用发射**。此功能适用于 JT65 和 Q65，并需开启 **启用甚高频和子模式功能**。
WS 也会处理 EME65 转发的解码。
你的 **DX 呼号** 和 **DX 网格** 会被发回，以便 WS-MAP 或 EME65
跟随。

如果多个 WS 实例监视同一个源，请在应当响应点击的实例中点击
**独占 WS-MAP**。使用
menu:解码[WS-MAP/EME65 源] 选择源（见 <<MENU_DECODE>>）。

[[QSY_WINDOWS]]
=== 信息创建器和 QSY监听

这些窗口帮助你与 QSO 对方约定 QSY，例如
从 EME 频率转到另一个波段。

[cols="2,5",options="header"]
|===
|窗口 |功能

|menu:显示[信息创建器]
|为 **DX 呼号** 中的电台生成简短的 QSY 请求（波段、模式和 kHz），
将其放入自由文本信息并开启 **启用发射**。

|menu:显示[启用信息弹出窗口]
|收到请求你 QSY 的信息时，弹出窗口显示该请求，
并让你回复 OKQSY 或 NOQSY。

|menu:显示[QSY监听]
|列出收到的所有 QSY 请求，包括 UTC、呼号、频率和模式。
|===

[[DIAGNOSTIC_MODE]]
=== 诊断模式

诊断模式收集数据，用于查找 WS 或其电台
控制方面的问题（Hamlib 错误、COM 端口无响应等）。

. 选择 menu:保存[诊断模式]。
. 关闭并重新启动 WS，然后重现故障。
. 故障出现后尽快关闭 WS：日志文件增长很快。

WS 会在桌面上创建一个 `logs` 文件夹（每个
`--rig-name` 实例有一个子文件夹），其中包含 `ws_syslog.log` 和 `WS_RigControl.log`。
用文本编辑器打开它们，或发送给开发人员。诊断
模式会在下次关闭 WS 时自动关闭；如需提前取消，
请选择 menu:保存[默认事件记录]。

[[DARK_STYLE]]
=== 深色样式

menu:显示[启用黑夜模式] 可立即将 WS 切换为深色主题，无需
重启。它还会调整瀑布图线条和按钮颜色。使用
深色样式时，请在 **颜色** 选项卡上选择较柔和的（粉彩）背景颜色。
见 <<MENU_VIEW>>。
