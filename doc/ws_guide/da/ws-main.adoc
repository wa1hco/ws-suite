== WS brugervejledning

[preface]
== Om denne vejledning

WS er en programpakke til digital kommunikation med svage signaler i
amatørradio: *WS* (hovedprogrammet), *WS-MAP* (bredbåndsmonitor til
Q65/FT8) og *EME65* (bredbånds-JT65/Q65 til EME). WS udsprang af
_WSJT-X_ og hed tidligere _WSJT-X Improved_. Alle modes og grundlæggende
betjeningsprocedurer er de samme som i WSJT-X; for dem er
https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-3.0.0-rc1.html[WSJT-X User Guide]
fortsat referencen.

Denne vejledning er bevidst kort. Den forklarer alle menuer og alle
indstillinger i WS, og hvad WS tilføjer til WSJT-X.
