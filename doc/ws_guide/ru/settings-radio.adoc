[[SETTINGS_RADIO]]
=== Радио

image::settings-radio.png["Настройки, вкладка Радио",align="center"]

==== Трансивер

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Трансивер*
|Модель вашего трансивера или управляющая программа, которой принадлежит трансивер (DX Lab Suite
Commander, Flrig, Ham Radio Deluxe, Hamlib NET rigctl, OmniRig Rig 1/2,
TCI Client). *Отключено* означает отсутствие управления по CAT.

|*Интервал опроса*
|Как часто WS считывает частоту и режим трансивера. Для большинства трансиверов
подходит 1–3 с. Недоступно для трансиверов, которые сами сообщают об изменениях.
|===

==== Управление CAT

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Порт*
|Последовательный порт вашего CAT-интерфейса (например, COM3 или /dev/ttyUSB0). Для
управляющей программы поле становится *Сетевой сервер* или *Сервер TCI*
(`host:port`); оставьте его пустым для значения по умолчанию на этом компьютере. Для
некоторых SDR-комплектов оно становится *USB устройство*.

|*Скорость* / *Бит данных* / *Стоп бит*
|Должны совпадать с меню CAT вашего трансивера. *По умолчанию* сохраняет значение, известное Hamlib
для вашей модели.

|*Управление потоком*
|Обычно *Отключено*. Некоторым трансиверам, особенно ряду моделей Kenwood, нужно
*Аппаратное* (RTS/CTS). При неверной настройке CAT не отвечает.

|*Управление линиями DTR/RTS CAT порта.* *DTR:* / *RTS:*
|Постоянно держит DTR или RTS в состоянии *Высокий* или *Низкий*, например для питания
интерфейса. Оставьте пустым, если не уверены, что это нужно. Недоступно для
линии, которая используется для PTT на том же порту.
|===

==== Обновить Hamlib

Эти параметры пришли из WSJT-X Improved и отсутствуют в WSJT-X. Они работают
только в Windows; в Linux и macOS группа называется *Hamlib Version*
и просто показывает используемую версию.

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*64-бит* / *32-бит*
|Какую DLL Hamlib загружать. Выберите ту, что соответствует вашей установке WS.

|*Обновить Hamlib*
|Загружает последнюю DLL Hamlib, которая часто добавляет или исправляет поддержку трансиверов.
Текущая DLL сохраняется как резервная копия. Перезапустите WS, чтобы использовать новую.

|*Отменить обновление*
|Возвращает резервную DLL, также после перезапуска.

|*Используется* / *Резервная копия*
|Версия Hamlib, с которой работает WS, и версия резервной копии.
|===

==== Управление PTT

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*VOX*
|Передатчик включается через VOX трансивера. Интерфейс не нужен.

|*CAT*
|PTT командой CAT, если трансивер это поддерживает. Обычно правильный выбор
при работе с управляющей программой, например OmniRig или Flrig.

|*DTR* / *RTS*
|Трансивер включается на передачу линией управления последовательного порта. Многие трансиверы с USB позволяют назначить эту линию на
PTT (Icom: USB SEND, Yaesu: PC KEYING). *RTS* недоступна на
CAT-порту при управлении потоком *Аппаратное*.

|*Порт*
|Последовательный порт для *DTR* / *RTS*; может совпадать с CAT-портом. Значение
*CAT* предназначено для интерфейсов вроде OmniRig, которые переключают линии удалённо.

|*Включить TX Inhibit*
|Для станций, которые делят диапазон с приоритетным трансивером (только PTT через *DTR* / *RTS*):
другая программа может запретить WS передачу, пока тот трансивер передаёт.
|===

==== Подключение звуковой карты к трансиверу

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Rear/Data* / *Front/Mic*
|Выбирает звуковой вход передатчика по CAT, если трансивер это поддерживает.
Действует только при способе PTT *CAT*. Обычно лучше *Rear/Data*.
|===

==== Режим

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Отключено* / *USB* / *Data/Pkt*
|Режим, который WS устанавливает на трансивере. *Data/Pkt*, если он есть у трансивера (часто
выбирает задний звуковой вход и более широкий фильтр), иначе *USB*.
*Отключено* не меняет режим.
|===

==== Разнос частот VFO

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Трансивер*
|Использует собственный split трансивера (VFO A и B).

|*Fake It*
|Использует только VFO A и перестраивает его для каждой передачи. Работает с любым трансивером.

|*Отключено*
|Без split (не рекомендуется).
|===

При работе со split WS сдвигает частоту передачи шагами по 500 Гц так, чтобы звук передачи
оставался между 1500 и 2000 Гц. Тогда гармоники звука попадают за пределы
фильтра трансивера, и ваш сигнал остаётся чистым. Это действует в FT4, FT8 и
FST4, а во всех видах связи - когда *Включить функции VHF и подрежима* выключено.
Доплеровскому слежению тоже нужен split.

==== Тест CAT и Тест PTT

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Тест CAT*
|Подключается к трансиверу с этими настройками. Зелёный: всё в порядке. Красный: ошибка, с
сообщением.

|*Тест PTT*
|Включает передатчик без звука; повторный щелчок отключает. Проверьте, что
трансивер и интерфейс переключаются как ожидается. При *VOX* вместо этого используйте *Настройка* в
главном окне.
|===

==== Данные трансивера

Эти параметры пришли из WSJT-X Improved и отсутствуют в WSJT-X.

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Показывать PWR, SWR и ALC*
|Во время передачи показывает выходную мощность (в ваттах, рядом с регулятором *Pwr*)
а также КСВ и ALC в строке состояния. При КСВ выше 1,5 поле становится
жёлтым, выше 2,0 - красным. Нужен трансивер, который сообщает эти значения; недоступно
при *Отключено*, OmniRig, DX Lab Suite Commander, Ham Radio Deluxe
и Kenwood TS-480/850/870.

|*Остановить Tx при КСВ > 2.5*
|Сразу прекращает передачу и показывает предупреждение. Проверьте антенну.

|*Выделять ALC > 50%* / *Выделять ALC > 90%*
|Окрашивает поле состояния в жёлтый / красный, когда ALC превышает предел, чтобы вы
заметили перегрузку по входу.
|===

Последним трём параметрам нужно *Показывать PWR, SWR и ALC*.
