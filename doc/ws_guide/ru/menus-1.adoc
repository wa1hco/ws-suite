[[MENU_FILE]]
=== Файл

image::menu-File.png[Меню Файл]

[cols="2,5",options="header"]
|===
|Пункт меню |Что делает

|*Открыть* kbd:[Ctrl+O]
|Останавливает *Монитор* и открывает записанный файл `.wav`, который затем декодируется
так же, как звук в реальном времени.

|*Открыть следующий в папке*
|Открывает и декодирует следующий файл `.wav` в той же папке.

|*Декодировать оставшиеся файлы в папке* kbd:[Shift+F6]
|Открывает и декодирует по очереди все последующие файлы `.wav` в папке.

|*Delete all {asterisk}.wav & {asterisk}.c2 files in SaveDir*
|После подтверждения удаляет все сохранённые звуковые файлы (`.wav` и `.c2`)
в папке сохранения.

|*Стереть ALL.TXT*
|После подтверждения удаляет `ALL.TXT` - запись всего, что вы
приняли и передали.

|*Стереть wsjtx_log.adi*
|После подтверждения удаляет ваш файл лога ADIF.

|*Стереть wsjtx.log*
|После подтверждения удаляет `wsjtx.log` - простой список QSO, который записывает
*QSO в лог*. WS использует его для фильтров "сработаны сегодня" и для того, чтобы
«Ожидание и перехват» не звало станции, которые уже есть в логе.

|*Стереть список игнорирования*
|После подтверждения очищает список игнорирования (заполняемый кнопкой *Игнор*).

|*Стереть хеш-таблицу WSPR*
|После подтверждения удаляет таблицу, по которой WSPR восстанавливает хешированные
составные позывные.

|*Стереть список вызывающих Q65*
|После подтверждения удаляет список позывных, которые WS запоминает
из декодирований Q65.

|*Очистка Cabrillo лога ...*
|После подтверждения стирает из контестового лога все QSO текущего соревнования.
В логе ADIF они остаются, но экспортировать их в Cabrillo
больше нельзя. Порядковый номер снова начинается с 1, а счёт в окне
*Активные станции* сбрасывается.

|*Экспорт Cabrillo лог...*
|Сохраняет контестовый лог в файл Cabrillo для отправки.

|*Открыть папку логов*
|Открывает папку данных WS (логи, `ALL.TXT` и т. д.) в файловом менеджере.

|*Настройки...*
|Открывает окно *Настройки* (также kbd:[F2]). См. главу «Настройки».

|*Выход*
|Закрывает WS.
|===

NOTE: В macOS *Настройки* (как *Preferences*) и *Выход* (как *Quit*)
находятся в меню приложения, а не в меню *Файл*.

[[MENU_CONFIGURATIONS]]
=== Конфигурация

image::menu-Config.png[Меню Конфигурация]

_Конфигурация_ - это полный именованный набор настроек. Многие операторы
держат по одной конфигурации на вид связи или на вариант станции (например, "FT8 HF" и
"Q65 EME") и переключаются между ними двумя щелчками.

В меню перечислены все конфигурации; используемая отмечена галочкой. Каждая
конфигурация открывает небольшое подменю (слева - другая конфигурация,
справа - используемая):

image:menu-Config-Other.png[Подменю другой конфигурации] image:menu-Config-Current.png[Подменю используемой конфигурации]

[cols="2,5",options="header"]
|===
|Пункт меню |Что делает

|*Переключить на*
|WS перезапускает главное окно с настройками этой конфигурации.
Для используемой конфигурации не показывается.

|*Клон*
|Создаёт копию с именем "_name_ - Copy". Переименуйте её и измените настройки,
чтобы получить новую конфигурацию.

|*Клонировать в ...*
|Перезаписывает все настройки этой конфигурации настройками другой,
выбранной вами. Запрашивает подтверждение. Показывается, только если конфигураций
больше одной.

|*Сброс*
|После подтверждения возвращает этой конфигурации значения по умолчанию.

|*Переименовать ...*
|Даёт конфигурации новое имя.

|*Удалить*
|После подтверждения удаляет конфигурацию. Используемую конфигурацию
удалить нельзя, поэтому для неё этот пункт не показывается.
|===

TIP: Чтобы запустить WS сразу в нужной конфигурации, используйте параметр командной строки
`--config NAME` (или `-c NAME`), например `ws -c Echo`.

[[MENU_VIEW]]
=== Показывать

image::menu-View.png[Меню Показывать]

[cols="2,5",options="header"]
|===
|Пункт меню |Что делает

|*Водопад*
|Открывает окно Wide Graph со спектром и водопадом.

|*Астрономические данные*
|Открывает (галочка) или закрывает окно астрономических данных: данные Луны и Солнца,
доплеровский сдвиг EME, доплеровское слежение и частота скеда.

|*Усреднение сообщений* kbd:[F7]
|Открывает окно усреднения сообщений, где показаны периоды, использованные для
усреднённых декодирований (JT4, JT65, Q65).

|*Эхо-график* kbd:[F8]
|Открывает окно эхо-графика для режима Echo.

|*Быстрый график* kbd:[F9]
|Открывает окно быстрого графика для быстрых видов связи (MSK144 и быстрый JT9).

|*Контест лог*
|Показывает QSO текущего соревнования и их количество.

|*Лог лисы*
|Показывает QSO, проведённые в роли Fox в режиме DX-экспедиции FT8.

|*Схема выделения цветом*
|Небольшая легенда текущих цветов выделения декодирований (CQ, мой позывной,
новая DXCC, пользователь LotW и т. д.). Цвета задаются на вкладке настроек
*Цвета*.

|*Активные станции*
|Список недавно декодированных станций, например чтобы найти самые дальние
в соревновании с очками за расстояние, с полями *Темп*, *Очки* и *Смены диапазона*.
Щелчок по строке вызывает эту станцию. Если запущен WS-MAP, показываются
станции, которые WS-MAP декодирует во всей своей полосе; одиночный щелчок
передаёт в WS данные QSO и частоту скеда, двойной щелчок вызывает
станцию.

|*SWL Mode*
|Скрывает нижнюю панель управления, чтобы панели декодирования занимали всё окно.
Удобно, когда одновременно работают несколько экземпляров. Размер и положение этого
вида запоминаются отдельно.

|*Конструктор сообщений*
|Составляет специальные сообщения, например запрос QSY на другой диапазон или вид связи,
либо короткое заготовленное сообщение, для станции из поля *Позывной DX*. При открытии
также включается *Всплывающие сообщения*.

|*QSY-монитор*
|Показывает специальные сообщения, которые другие станции отправляют друг другу и вам.

|*Всплывающие сообщения*
|Когда специальное сообщение адресовано вам, появляется всплывающее окно с
кнопками для ответа.

|*Кнопки диапазонов*
|Показывает ряд кнопок КВ-диапазонов (от 160 м до 70 см); текущий диапазон
зелёный. Щелчок по кнопке переводит на предпочтительную частоту этого диапазона
и вида связи (задаётся флажком *Предп.* на вкладке настроек *Частоты*).
Щелчок правой кнопкой по кнопкам от 80 м до 10 м (FT8, FT4, FT2) переводит на обычную частоту
DX-экспедиций, на 6 м (FT8) - на 50,323 МГц. См. также
menu:Помощь[Команды управления мышью].

|*Кнопки VHF / UHF*
|Заменяет КВ-кнопки набором для VHF/UHF/СВЧ (от 8 м до 24 ГГц).
Видно, только если включено *Кнопки диапазонов*.

|*Тёмная тема*
|Переключает все окна на тёмную тему. Это больше, чем простая тёмная
таблица стилей: WS также меняет некоторые внутренние настройки и использует таблицу стилей,
оптимизированную для неё. После этого смените цвета выделения на вкладке настроек
*Цвета* на более мягкие пастельные тона.

|*Позывные на водопаде*
|Подменю, см. ниже.
|===

==== Позывные на водопаде

image::menu-View-Callsign_overlay.png[Подменю Позывные на водопаде]

WS может писать декодированные позывные прямо на водопаде, на той
частоте, где была услышана каждая станция.

[cols="2,5",options="header"]
|===
|Пункт меню |Что делает

|*Показывать декодированные позывные*
|Включает или выключает метки с позывными. При выключении все метки удаляются.
Открытие файла `.wav` тоже их очищает.

|*Держать 1 период* ... *Держать 5 периодов*
|Сколько метка остаётся на экране после последнего декодирования станции, в
периодах Tx/Rx (по умолчанию 2). То же значение можно задать в окне Wide Graph.

|*Размер шрифта*
|image:menu-View-Callsign_overlay-Callsign_font.png[Подменю Размер шрифта] +
Размер меток: *Мелкий (7 пт)*, *Обычный (8 пт)*, *Средний (10 пт)* или *Крупный (12 пт)*.

|*Прозрачность*
|image:menu-View-Callsign_overlay-Callsign_transparency.png[Подменю Прозрачность] +
Насколько водопад просвечивает сквозь метки: *Нет*, *Низкий*, *Средняя* или *Высокий*.

|*Положение*
|image:menu-View-Callsign_overlay-Callsign_position.png[Подменю Положение] +
*Вверху водопада* или *Внизу водопада (над разделителем)*, чтобы
самые новые сигналы вверху оставались открытыми.
|===

[[MENU_SAVE]]
=== Сохранить

image::menu-Save.png[Меню Сохранить]

[cols="2,5",options="header"]
|===
|Пункт меню |Что делает

|*Нет*
|Звуковые файлы не сохраняются.

|*Сохранить декодированные*
|Сохраняет в папку сохранения звук (`.wav`) каждого периода, в котором было хотя бы одно

|*Сохранить все*
|Сохраняет звук каждого периода.

|*Удалять сохранённые файлы через 30 дней*
|При каждом запуске программы WS удаляет из папки сохранения все файлы
старше 30 дней.

|*Не разделять ALL.TXT*
|Все декодирования и передачи записываются в один `ALL.TXT` (по умолчанию).

|*Разделять ALL.TXT по годам*
|Один файл на год, например `2026-ALL.TXT`.

|*Разделять ALL.TXT по месяцам*
|Один файл на месяц, например `2026-09-ALL.TXT`.

|*Отключить запись ALL.TXT*
|В `ALL.TXT` ничего не записывается.

|*Журнал событий по умолчанию*
|Обычное минимальное внутреннее журналирование. Также снова отключает *Режим диагностики*.

|*Режим диагностики*
|Собирает подробные данные для поиска проблем в WS или в его связи с
трансивером. Вступает в силу после перезапуска и отключается сам при
следующем закрытии WS. На рабочем столе появляется папка `logs` с
`ws_syslog.log` и `WS_RigControl.log`; по просьбе разработчиков отправьте их им.
Закройте WS вскоре после появления неисправности, так как файлы быстро растут.

|*Отключить журнал событий*
|Выключает внутреннее журналирование событий.
|===

[[MENU_LANGUAGE]]
=== Язык

image::menu-Language.png[Меню Язык]

Выбирает язык интерфейса WS. По умолчанию используется английский;
остальные пункты - переводы, поставляемые с WS, каждый показан
на своём языке.

Когда вы выбираете язык, WS спрашивает, перезапустить ли окно сейчас:

[cols="2,5",options="header"]
|===
|Кнопка |Что делает

|*Перезапустить сейчас*
|За несколько секунд пересоздаёт главное окно на новом языке, так же
как при переключении на другую конфигурацию. Сам WS продолжает работать.
Пока WS передаёт или настраивается, окно не перезапускается; новый
язык тогда применяется при следующем запуске WS.

|*Позже*
|Сохраняет текущий язык до следующего запуска WS.
|===

Выбор действует для всех конфигураций. Запуск WS с
`--language <code>` (например, `ws --language de`) переопределяет его на
этот сеанс.

NOTE: Переводы делают добровольцы, и они могут быть неполными; ещё
не переведённые тексты показываются на английском.
