==== Параметры декодирования JT65 VHF/UHF/СВЧ

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Выбранные стили декодера*
|Насколько настойчиво работает декодер JT65 с мягкими решениями (до 10^n/2^ шаблонов).
Большие значения немного чувствительнее, но медленнее; для большинства станций подходит 6 или 7.

|*Уровень агрессивного декодирования*
|Порог для Deep Search в JT65 (0–10). Более высокие уровни дают больше декодирований,
но и больше ложных.

|*Двухпроходное декодирование*
|JT65: второй проход декодирования после вычитания сигналов, найденных в первом
проходе.
|===

==== Настройки интерфейса для мониторов высокого разрешения

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Масштабирование HighDPI (нужен перезапуск)*
|Следует масштабированию экрана операционной системы, поэтому на мониторах 4K элементы управления
крупнее и правильно пропорциональны. По умолчанию включено.

|*Увеличенная высота вкладок (нужен перезапуск)*
|Позволяет вкладкам сообщений Tx в главном окне становиться выше.
|===

==== Разное

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Ухудшить S/N .wav файла* / *Полоса пропускания приемника*
|Для офлайн-тестов чувствительности: добавляет шум к открываемым файлам .wav, понижая
S/N на заданное число дБ. Чтобы значение было точным, установите *Полоса пропускания приемника* равной шумовой
полосе вашего приёмника.

|*Задержка передачи*
|Минимальное время между PTT и началом звука передачи (от 0 до 0,5 с). FT4 и
FT2 всегда используют 20 мс.

|*Расстояние между тонами*: *x 2* / *x 4*
|Удвоенное / учетверённое обычное расстояние между тонами для передатчиков НЧ/СЧ, которые
делят частоту на 2 или 4. Можно включить только один из вариантов.

|*Спектр водопада*: *Малый уровень* / *Самый чувствительный*
|*Малый уровень* (по умолчанию) использует БПФ с оконной функцией, поэтому сильные сигналы меньше
расплываются по водопаду. *Самый чувствительный* работает без окна и немного лучше показывает очень
слабые следы.
|===

IMPORTANT: *Задержка передачи* не заменяет аппаратный секвенсор. Чтобы защитить
реле приём/передача и предусилители, используйте его и проверьте правильность последовательности переключения.

==== Особый вид активности

Включите флажок и выберите одну активность; тогда WS формирует соответствующие
форматы сообщений.

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*NA VHF*
|Североамериканские соревнования на VHF/UHF/СВЧ и другие, где контрольным номером служит
4-символьный локатор.

|*NCCC Sprint*
|Только с *NA VHF*: протокол коротких сообщений NCCC Sprint для FT4 (и FT2).

|*EU VHF Contest*
|Европейские соревнования на VHF и выше: рапорт, порядковый номер и 6-символьный локатор.

|*WW Digi Contest* / *ARRL Digi Contest*
|Соревнование World-Wide Digi / ARRL International Digital Contest.

|*Q65 Pileup*
|Вместо рапорта передаётся 4-символьный локатор, что даёт DX-оператору
чувствительность уровня q3. Особенно полезно для DX-экспедиций EME на 6 м.

|*ARRL Field Day* / *FD Exch*
|Ваш контрольный номер: число передатчиков, класс и секция ARRL/RAC или "DX"
(например, `6A SNJ`).

|*Сообщения FT Roundup* / *Номер FT RU*
|FT Roundup и подобные соревнования. Контрольный номер: штат США, провинция Канады или
"DX" (также для Аляски и Гавайев).

|*Fox* / *Hound*
|Режим DX-экспедиции FT8: *Fox* - для DX-экспедиции, *Hound* - чтобы её вызывать. Перед использованием
прочитайте руководство пользователя режима DX-экспедиции FT8.

|*Режим SuperFox*
|С *Fox* или *Hound*: передача или приём сигнала SuperFox.

|*OTP* / *Ключ* / *Интервал*
|С *Fox* или *Hound*: проверка Fox с помощью одноразового пароля (нужен
интернет). Fox вводит свой 16-символьный *Ключ* и подписывает каждое N-е
сообщение, где N - *Интервал* (1 = каждое сообщение).

|*Показывать сообщения OTP* / *OTP URL*
|Для Hound: WS проверяет коды Fox по адресу *OTP URL* (по умолчанию
`https://www.9dx.cc`). *Показывать сообщения OTP* выводит проверочные
сообщения в панели «Декодирование в полосе обзора».

|*CQ с названием соревнования* / *Название соревнования*
|Зовёт, например, `CQ PACC` вместо CQ TEST, RU или WW. Недоступно с
*Fox*, *Hound* или *Q65 Pileup*.
|===

==== Отправлять QSO в Cloudlog или Wavelog

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Отправлять QSO в Cloudlog или Wavelog*
|Включите флажок в заголовке группы, чтобы отправлять каждое внесённое в лог QSO на ваш сервер Cloudlog или
Wavelog.

|*API URL*
|Базовый адрес вашей установки, без завершающей косой черты
(например, `https://log.example.com`).

|*API-ключ* / *ID станции*
|API-ключ с правом записи и ID профиля станции из Cloudlog/Wavelog.

|*Проверить API-ключ*
|Отправляет тестовое QSO в пробном режиме (dry run). Кнопка становится зелёной, если ключ
позволяет запись, оранжевой - если он только для чтения, красной - если он недействителен.
|===

==== Отправлять QSO на eQSL.cc

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Отправлять QSO на eQSL.cc*
|Включите флажок в заголовке группы, чтобы загружать каждое внесённое в лог QSO на eQSL.cc.

|*Имя пользователя* / *Пароль*
|Ваши данные для входа на eQSL.cc.

|*QTH*
|Псевдоним вашего QTH, если на eQSL.cc у вас больше одного QTH.
|===

NOTE: Пароль eQSL.cc и API-ключ хранятся в файле настроек
в незашифрованном виде.
