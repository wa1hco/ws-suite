==== Выделение декодирований

WS раскрашивает декодирования по категориям. Для всех категорий, кроме *CQ в сообщении*,
*Мой позывной в сообщении*, *Передаваемое сообщение* и *Пользователь LotW*, нужно
*Показывать DXCC, локатор и статус «уже сработан»* на вкладке *Общие*.

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|Список выделения
|Одна строка на категорию; флажок включает её. Перетаскивайте строки вверх или вниз,
чтобы задать приоритет: строка выше побеждает. Цвет текста и цвет фона
задаются отдельно, поэтому «не заданный» цвет берётся из следующей включённой строки ниже.

|Контекстное меню (правая кнопка)
|*Цвет переднего плана...* / *Фоновый цвет ...* выбирают цвет,
*Отменить основной цвет* / *Отмена фонового цвета* сбрасывают его.
*Сбросить значения по умолчанию* восстанавливает для этой строки значения WSJT-X по умолчанию.

|*CQ в сообщении*, *Мой позывной в сообщении*, *Передаваемое сообщение*
|Вызовы CQ, CQDX и QRZ; декодирования, адресованные вам; переданные вами сообщения.

|*Новая DXCC*, *Новый континент*, *Новая CQ зона*, *Новая ITU зона*, *Новый штат США*, *Новый локатор*, *Новый позывной*
|Ещё нет в вашем логе. Варианты *... на диапазоне*: ещё не сработано на
текущем диапазоне.

|*Пользователь LotW*
|Станция загружала свой лог в LoTW в пределах срока, заданного в
<<LOTW_VALIDATION,Мировой лог LotW>>.

|*Сбросить выделение к умолчаниям WSJT-X*
|Исходные цвета и порядок WSJT-X. С ними начинает новая установка.

|*Сбросить выделение к умолчаниям WS*
|Схема WS с пастельными цветами, которые подходят и для тёмной темы. Пользователи
LoTW показываются чёрным, остальные станции - тёмно-красным; CQ от станции,
с которой вы уже работали, получает серый фон.

|*Пересканировать ADIF лог*
|Заново читает `wsjtx_log.adi` и перестраивает статус «уже сработан». На
кнопке показано число QSO. Этот файл можно заменить экспортом ADIF
из вашей программы ведения лога.

|*Выделение по режимам*
|Статус «уже сработан» учитывается отдельно для каждого вида связи.

|*Искомые поля только в локаторе*
|Локатор считается новым, только если его поле (первые два символа, например JO)
ещё не сработано.

|*Включить дополнительные объекты WAE*
|Показывает дополнительные территории DARC WAE / CQ Marathon (например, Sicily, Shetland Is.)
под их собственными названиями. Если флажок снят, они показываются как их страна DXCC.

|*Выделять также сообщения с 73 или RR73*
|Сообщения 73 и RR73 выделяются как CQ и получают страну и отметки
«уже сработан». Они также проходят фильтр *Только CQ*, который тогда
называется *CQ/73*. По умолчанию включено.

|*Выделять все сообщения*
|Каждое декодированное сообщение выделяется как CQ и получает страну и
отметки «уже сработан», а не только вызовы CQ (и сообщения 73 при параметре
выше). По умолчанию выключено.

|*Выделять оранжевым:* / *Выделять синим:*
|Белый текст на оранжевом / синем фоне для позывных, локаторов,
префиксов и направлений CQ, введённых в поле ниже. Эти записи также
запускают оповещение *Нужные позывные, локаторы, префиксы и направленные вызовы* на вкладке *Оповещения*.
|===

Записи для *Выделять оранжевым* и *Выделять синим* (заглавными или строчными буквами):

* Позывные: запятая после каждого позывного, включая последний: `K1JT, DG2YCB,`
* Локаторы: `JO33, JN58,`
* Префиксы из 2 или 3 символов между точками с запятой: `;DL;KH6;`. Однобуквенный
  префикс, например `;K;`, совпадает только с позывными, у которых на втором месте цифра
  (K1ABC, но не KH6ABC).
* Все позывные, начинающиеся с одной буквы: `;K*;`. Префиксы исключаются, если заключить
  их в восклицательные знаки: `;K*;!KH6!KL!KP!`
* Направления CQ с запятой до и после: `,EU,` выделяет "CQ EU ...".

[[LOTW_VALIDATION]]
==== Мировой лог LotW

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Users CSV file URL* / *Скачать сейчас*
|Источник списка ARRL пользователей LoTW и дат их последней загрузки.
*Скачать сейчас* загружает свежую копию. Сам WS загружает список, только если
файла нет и включено выделение *Пользователь LotW*.

|*Файл CSV загружен не ранее*
|Станции считаются пользователями LoTW, только если их последняя загрузка была позже.
|===

==== Загрузки

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Загрузить последний CTY.dat*
|Обновляет данные о странах, зонах и префиксах с country-files.com и
заново сканирует лог. *Версия файла CTY* показывает используемую версию.

|*Загрузить базу штатов позывных США*
|Данные «позывной - штат» для *Показывать штаты США* (вкладка *Общие*), используемые, когда в
сообщении нет пригодного локатора. *БД штатов позывных* показывает её размер и дату.

|*Загрузить CALL3.TXT для наземных связей* / *Загрузить CALL3.TXT для EME*
|База позывных и локаторов для кнопки *Поиск* и для Deep Search в JT4/JT65;
версия для EME предназначена для Deep Search в JT65. Предыдущий файл
сохраняется как `CALL3_backup.TXT`. *Версия файла CALL3* показывает версию.
|===
