[[SETTINGS_FILTERS]]
=== Фильтры

image::settings-filters.png["Настройки, вкладка Фильтры",align="center"]

Фильтры определяют, какие декодирования появляются в панели *Декодирование в полосе обзора*.
Списки на этой вкладке работают вместе с быстрыми фильтрами в меню *Фильтры*
(см. <<MENU_FILTERS>>), где также включаются и выключаются фильтры
по территориям.

Пока фильтр скрывает декодирования, строка состояния внизу слева
главного окна меняется с зелёного "Прием" на бирюзовое "Receiving, Filters On".

Чтобы временно снова видеть всё, включите *BP* (bypass) в главном
окне: все фильтры игнорируются, а строка показывает "Receiving, Filters
bypassed". Снимите флажок, чтобы вернуться к своим фильтрам.

NOTE: Чёрный список, белый список и «Всегда пропускать» автоматически отключаются
в особых режимах работы, чтобы вы не пропустили станцию. Для Hound чёрный и
белый списки остаются активными.

==== Списки фильтров

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Территории 1-4*
|До четырёх названий стран или частей названий для пунктов *Скрывать станции с
территории 1-4* и *Выделять станции с территории 1-4* в меню
*Фильтры*; эти пункты меню затем показывают ваш текст. Пишите название так,
как его показывает WS, например `Japan`, `U.S.A.` или `Canary Is.`.

|*Чёрный список* +
*Скрывать сообщения, содержащие следующие позывные или ключевые слова*
|Скрывает сообщения, содержащие любую из записей: полные позывные, части
позывных, локаторы или слова (например, пиратские позывные или контестовые сообщения).

|*Белый список* +
*Показывать только сообщения, содержащие следующие позывные или ключевые слова*
|Показывает только сообщения, содержащие одну из записей; все остальные
скрываются, кроме тех, что есть в списке «Всегда пропускать».

|*Всегда пропускать* +
*Всегда пропускать сообщения со следующими ключевыми словами*
|Сообщения с этими записями показываются всегда, даже если их скрыли бы чёрный список,
белый список или пункт «Скрывать» для территории, континента или
уже сработанных станций.
|===

В каждом списке двенадцать полей, по одной записи в поле. Записи преобразуются
в заглавные буквы. Список работает, только пока включён его флажок.

==== Параметры

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Применять фильтры только к позывным вызывающих станций*
|Списки сверяются только с позывным вызывающей станции (обычно это
второе слово, а для направленных CQ, например `CQ NA`, - третье). Тогда запись
должна совпадать с началом позывного, так что работает префикс вроде `JA`.
Если флажок снят, запись совпадает в любом месте сообщения.

|*Применять фильтры только для «Ожидание и ответ», CQ: First и т. п. (все сообщения по-прежнему отображаются)*
|В панели *Декодирование в полосе обзора* ничего не скрывается; фильтры лишь определяют, каким
станциям отвечают «Ожидание и перехват» и варианты *CQ:*. См. <<WAIT_FEATURES>>.

|*Быстрые фильтры: Скрывать/Игнорировать/Выделять «сработаны сегодня и вчера» вместо «сработаны сегодня» (UTC)*
|Три пункта «сработаны сегодня» в меню *Фильтры* также учитывают
станции, сработанные вчера (UTC).
|===
