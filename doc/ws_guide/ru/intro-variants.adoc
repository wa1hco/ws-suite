== Три варианта интерфейса

WS всегда выпускается в *трёх вариантах интерфейса*. У них одинаковые функции,
меню и настройки; различается только компоновка главного окна.
Для каждого варианта есть свой установщик.

[cols="1,3",options="header"]
|===
|Вариант |Для чего подходит

|*WS* (стандартный)
|Привычная компоновка WSJT-X. Этот вариант загружается по умолчанию.

|*WS AL* (альтернативная компоновка)
|Более компактное окно с увеличенной панелью декодирования в полосе обзора, так что прокручивать приходится меньше.

|*WS Widescreen*
|Широкие мониторы: элементы управления перенесены вбок, а панели декодирования занимают всю высоту.
|===

TIP: Варианты можно установить рядом в разные папки и сравнить их.
Все они используют один и тот же файл настроек (`WS.ini`), поэтому ваша
конфигурация сохраняется. При первом запуске WS перенимает настройки
существующей установки WSJT-X.

Чтобы одновременно запустить несколько экземпляров, запускайте каждый со своим
`--rig-name=NAME`; тогда у каждого экземпляра будет свой файл настроек.
