[[SETTINGS_TXMACROS]]
=== Tx макросы

image::settings-tx_macros.png["Настройки, вкладка Tx макросы",align="center"]

Tx макросы - это короткие сообщения со свободным текстом, которые вы часто передаёте, например `TNX 73 GL`.
Они появляются в выпадающем списке сообщения *Tx5* в главном окне.

==== Список макросов

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|Текстовое поле и *Добавить*
|Введите сообщение и нажмите *Добавить*, чтобы добавить его в конец списка. Вводить можно только символы,
допустимые в сообщениях; текст преобразуется в заглавные буквы.

|*Удалить*
|Удаляет выделенные сообщения. Щелчок правой кнопкой → *Удалить* делает то же самое или,
если ничего не выделено, удаляет сообщение под курсором.

|Список
|Макросы в порядке выпадающего списка *Tx5*. Порядок меняется перетаскиванием.
Двойной щелчок по сообщению открывает его для редактирования. Щелчок, kbd:[Shift]+щелчок и
kbd:[Ctrl]+щелчок выделяют несколько сообщений.
|===

NOTE: Сообщение со свободным текстом ограничено 13 символами, включая пробелы.

TIP: Можно также ввести сообщение в поле *Tx5* в главном окне и нажать
kbd:[Enter]; оно будет добавлено в список. В FT8, FT4, FST4, MSK144 и Q65
в сообщении, начинающемся с `$DX` (или `$DXCALL`), это слово при передаче
заменяется основным позывным из поля *Позывной DX*.
