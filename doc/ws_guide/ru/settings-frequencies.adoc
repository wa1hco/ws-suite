[[SETTINGS_FREQUENCIES]]
=== Частоты

image::settings-frequencies.png["Настройки, вкладка Частоты",align="center"]

==== Калибровка по частоте

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Наклон* / *Смещение*
|Исправляет известную ошибку шкалы вашего трансивера: +
`rig frequency = Intercept + (1 + Slope / 1 000 000) × f` +
где *Смещение* (Intercept) в Гц, а *Наклон* (Slope) в ppm. Частоты, передаваемые в трансивер и
считываемые с него, корректируются, поэтому WS показывает истинную частоту. Если трансивер
точен, оставьте оба значения равными 0.
|===

TIP: Как измерить эти значения, описано в разделе _Frequency Calibration_
руководства пользователя WSJT-X (режим FreqCal).

==== Рабочие частоты

Частоты, предлагаемые в переключателе диапазонов главного окна. WS показывает
только записи для вашего *IARU регион* (вкладка *Общие*) и текущего вида связи.
Двойной щелчок по ячейке открывает её для редактирования.

[cols="2,5",options="header"]
|===
|Столбец |Что делает

|*IARU регион* / *Режим*
|Где и для какого вида связи предлагается запись. Записи со значением *Все* предлагаются
везде / во всех видах связи.

|*Частота*
|Частота трансивера в МГц.

|*Предп.*
|Предпочтительная запись для своего диапазона и вида связи. WS использует её, когда вы нажимаете
кнопку диапазона (menu:Показывать[]) или когда сам меняет диапазон (смена диапазонов). Предпочтительной
может быть только одна запись на диапазон и вид связи.

|*Описание*
|Ваша собственная подпись к записи, показываемая в переключателе диапазонов.

|*Дата/время начала* / *Дата/время окончания*
|Запись предлагается только в этот период, например для DX-экспедиции. Пусто = всегда.
|===

Щелчок правой кнопкой по таблице открывает следующие действия:

[cols="2,5",options="header"]
|===
|Пункт меню |Что делает

|*Удалить*
|Удаляет выделенные записи.

|*Вставить ...*
|Добавляет запись: *IARU регион*, *Вид*, *Частота (МГц)*, *Предпочтительна для
диапазона/режима*, *Описание* и необязательный диапазон дат.

|*Загрузить ...*
|Заменяет список списком из файла `.qrg` или `.qrg.json` (WS сначала спрашивает).

|*Сохранить как ...*
|Сохраняет список в файл; имя, оканчивающееся на `.qrg.json`, даёт файл JSON.
Если записи выделены, WS спрашивает, сохранить ли только их.

|*Объединить ...*
|Добавляет в список записи из файла `.qrg` или `.qrg.json`.

|*Сброс*
|Восстанавливает список по умолчанию (WS сначала спрашивает).
|===

==== Информация о станции

Сведения о станции по диапазонам. Двойной щелчок по ячейке открывает её для редактирования.

[cols="2,5",options="header"]
|===
|Столбец |Что делает

|*Диапазон*
|Диапазон, к которому относится строка.

|*Смещение*
|Прибавляется к отображаемой частоте, чтобы получить частоту трансивера, для
трансвертеров. Пример: для 144 МГц с ПЧ 28 МГц нужно -116 МГц. По умолчанию 0.

|*Описание антенны*
|Отправляется в PSK Reporter, пока вы работаете на этом диапазоне.
|===

Щелчок правой кнопкой по таблице даёт *Удалить* (удаляет выделенные строки) и
*Вставить ...* (добавляет строку: *Диапазон*, *Смещение (МГц)*, *Антенна*).

TIP: Чтобы быстро создать строки, выделите записи в *Рабочие частоты* (kbd:[Ctrl]+kbd:[A]
для всех) и перетащите их в *Информация о станции*. Затем заполните смещения и
антенны.
