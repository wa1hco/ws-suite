[[SETTINGS_ALERTS]]
=== Оповещения

image::settings-alerts.png["Настройки, вкладка Оповещения",align="center"]

WS может сообщать о выбранных декодированиях короткими голосовыми оповещениями ("New DXCC",
"My Call" и т. д.). Оповещения входят в каждую установку WS и
всегда воспроизводятся на звуковом устройстве компьютера по умолчанию, обычно через его
динамик.

WARNING: Для звуковых оповещений нужно второе звуковое устройство. Трансивер *не* должен быть
подключён через звуковое устройство по умолчанию, иначе оповещения уйдут в эфир.
Трансивер со встроенной звуковой картой USB (IC-7300, FT-991 и подобные) удовлетворяет
этому требованию. Проверьте перед включением (см. *Тест* ниже).

==== Звуковые оповещения

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Голоса*
|Выбирает голос для оповещений. В стандартной установке один голос - *по умолчанию*.

|*Тест*
|Воспроизводит тестовое оповещение на звуковом устройстве по умолчанию, чтобы можно было проверить,
откуда звучат оповещения.

|*Новая DXCC* / *Новая DXCC на диапазоне*
|Территория DXCC, с которой вы ещё не работали / не работали на текущем диапазоне.

|*Новый континент* / *Новый континент на диапазоне*
|Континент, ещё не сработанный / не сработанный на этом диапазоне.

|*Новая CQ зона* / *Новая CQ зона на диапазоне*
|Зона CQ, ещё не сработанная / не сработанная на этом диапазоне.

|*Новая ITU зона* / *Новая ITU зона на диапазоне*
|Зона ITU, ещё не сработанная / не сработанная на этом диапазоне.

|*Новый штат США* / *Новый штат США на диапазоне*
|Один из 50 штатов США, ещё не сработанный / не сработанный на этом диапазоне.
Штат определяется по позывному или по локатору, если тот указывает только на один штат.

|*Новый локатор* / *Новый локатор на диапазоне*
|QTH-локатор, ещё не сработанный / не сработанный на этом диапазоне. Учитываются только сообщения с локатором.

|*Мой позывной*
|Сообщение, адресованное вам.

|*DX Call или DX Grid в сообщении*
|Позывной из поля *Позывной DX* или локатор из поля *QTH Локатор* появляется в декодировании.

|*CQ в сообщении*
|Любой вызов CQ.

|*Нужные позывные, локаторы, префиксы и направленные вызовы*
|Декодирование совпадает с вашими записями *Выделять оранжевым* или *Выделять синим* на
вкладке *Цвета* (только пока это выделение включено) либо с записью белого списка,
пока включено menu:Фильтры[Выделять записи белого списка].

|*Получено сообщение*
|Пришло сообщение QSY для вашего позывного или для позывного DX. Это оповещение запускают только сообщения QSY,
поэтому оно звучит редко.

|*Включить звуковые оповещения*
|Главный выключатель: пока он выключен, оповещения не звучат. Когда он включён, кнопка
зелёная. В Windows WS при этом также воспроизводит короткий тестовый звук при запуске.
|===

Для категорий выше линии нужно включить *Показывать DXCC, локатор и статус «уже сработан»*
на вкладке *Общие*.

Оповещения работают независимо от выделения на вкладке *Цвета*. Но
увидеть, какое декодирование вызвало оповещение, можно только если там включено
соответствующее выделение, поэтому включайте одни и те же категории на обеих вкладках.

NOTE: Станции из списка игнорирования (добавленные кнопкой *Игнор* под
*QTH Локатор*) не вызывают оповещений, кроме *Мой позывной*, если только не включён флажок *BP* (bypass).
Список очищается командой menu:Файл[Стереть список игнорирования].

TIP: При выключенной смене диапазонов щёлкните правой кнопкой по кнопке *Смена диапазонов* в
главном окне для более длительной проверки звукового устройства по умолчанию.
