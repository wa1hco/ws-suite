=== Звук

==== Звуковая карта

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Вход* / *Выход*
|Звуковая карта, подключённая к трансиверу (например, USB audio CODEC трансивера),
настроенная на 48000 Гц, 16 бит. Поле справа выбирает канал:
обычно *Моно*, либо *Левый*, *Правый* или *Оба* в особых конфигурациях.

|*Обновить*
|Перечитывает список устройств, например после подключения трансивера по USB.

|*Звук через TCI (нужен перезапуск)* / *Rx 0 dB*
|Показывается только с трансивером TCI (например, SDR). Звук тогда идёт через
соединение TCI, а не через звуковую карту, и в полях устройств отображается *TCI audio*.
*Rx* понижает уровень принимаемого звука (от 0 до -50 дБ). После
изменения перезапустите WS.

|*Сортировать по алфавиту*
|Сортирует названия устройств по алфавиту и показывает только устройства, которые могут
записывать или воспроизводить звук PCM. Если флажок снят, используется системный порядок.

|*Скрывать подустройства ALSA CARD (только Linux)*
|Скрывает записи `CARD=`, которые обычно непригодны. Работает, только если
включено *Сортировать по алфавиту*.
|===

IMPORTANT: Если устройство вывода одновременно является звуковым устройством компьютера
по умолчанию, отключите все системные звуки. Иначе они уйдут в эфир.

==== Сохранить папку

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Расположение* / *Выбор*
|Папка для файлов `.wav`, записываемых через menu:Сохранить[]. По умолчанию - папка `save`
в папке логов.
|===

==== Папка AzEl

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Расположение* / *Выбор*
|Папка для `azel.dat`, где хранятся положение Солнца и Луны и доплеровский сдвиг для
программ слежения антенной. Файл обновляется каждую секунду, пока
открыто окно астрономических данных.

|*Дополнительная строка в azel.dat*
|Добавляет строку с Dpol, MNR, Dgrd и шириной эхо-сигналов для программ
слежения, которые читают эти значения.
|===

==== Запомнить уровень сигнала на передачу по диапазонам и видам излучения

[cols="2,5",options="header"]
|===
|Параметр |Что делает

|*Передача сообщений*
|Запоминает положение регулятора *Pwr* для каждого диапазона и восстанавливает его при смене диапазона.

|*Настройка передатчика*
|Хранит для *Настройка* отдельное значение *Pwr* на каждом диапазоне. По окончании настройки
регулятор возвращается к вашей мощности передачи.
|===
