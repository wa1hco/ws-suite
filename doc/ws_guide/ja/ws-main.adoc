== WSユーザーガイド

[preface]
== このガイドについて

WSは、アマチュア無線の微弱信号デジタル通信のためのプログラム群です。
**WS**(メインプログラム)、**WS-MAP**(広帯域Q65/FT8モニター)、
**EME65**(EME向け広帯域JT65/Q65)で構成されます。WSは
__WSJT-X__ から派生したもので、以前は __WSJT-X Improved__ と呼ばれていました。
すべてのモードと基本的な運用手順はWSJT-Xと同じです。それらについては
https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-3.0.0-rc1.html[WSJT-X User Guide]
を参照してください。

このガイドは意図的に簡潔にしています。WSのすべてのメニューとすべての
設定、そしてWSがWSJT-Xに追加した機能を説明します。
